## 🎯 这是什么？

### **基础定义**
计算机网络是计算机科学的一个核心领域，研究计算机之间如何连接、通信和共享资源。它涵盖从物理电缆到应用软件的完整技术栈，是互联网、云计算、移动通信等技术的基础。

**核心价值**：
- 理解互联网的工作原理
- 掌握网络设备的配置和管理
- 具备网络故障排查能力
- 为云计算、网络安全、DevOps等领域打下基础

### **通俗类比**
把计算机网络想象成城市的"交通系统"：
- **物理层**像"道路和桥梁"——铺设实际的交通基础设施
- **数据链路层**像"交通信号和车道规则"——控制车辆如何使用道路
- **网络层**像"导航系统"——规划从A地到B地的最佳路线
- **传输层**像"快递服务"——确保货物（数据）可靠送达
- **应用层**像"具体的业务"——邮件、购物、视频等实际应用

### **为什么学**
掌握网络技术的四大理由：
1. **理解互联网**：所有互联网应用都建立在网络技术之上
2. **职业发展**：网络工程师、运维、DevOps、云计算等岗位必备
3. **故障排查**：网络问题时能够快速定位和解决
4. **技术基础**：为深入学习云计算、网络安全、分布式系统奠定基础

### **各层核心概念**

**物理层**
- 专业说：负责在物理介质上传输原始比特流
- 关键词：光纤、双绞线、电信号、调制解调
- 通俗说：铺设"道路"，定义交通基础设施的物理规格

**数据链路层**
- 专业说：负责点到点的数据帧传输，实现MAC地址寻址
- 关键词：MAC地址、交换机、VLAN、以太网帧
- 通俗说：管理"车辆如何上道"，控制车道使用规则

**网络层**
- 专业说：负责路径选择和端到端数据包传输
- 关键词：IP地址、路由器、子网掩码、路由协议
- 通俗说："导航系统"，规划从A地到B地的最佳路线

**传输层**
- 专业说：提供端到端的可靠或不可靠传输服务
- 关键词：TCP、UDP、端口、流量控制
- 通俗说："快递服务"，确保货物（数据）可靠送达

**应用层**
- 专业说：为应用程序提供网络服务
- 关键词：HTTP、DNS、DHCP、SMTP
- 通俗说："具体业务"，用户实际使用的各种应用

## 📜 发展背景

### **网络技术演进**

| 时代 | 关键技术 | 特点 |
|------|---------|------|
| **1960-70年代** | ARPANET | 网络技术起源，分组交换 |
| **1980年代** | TCP/IP标准化 | 互联网基础协议形成 |
| **1990年代** | 万维网（WWW） | 互联网普及商业化 |
| **2000年代** | 宽带、无线 | 高速接入、移动网络兴起 |
| **2010年代** | 云计算、SDN | 网络虚拟化、软件定义 |
| **2020年代** | 5G、边缘计算 | 高带宽、低延迟、分布式 |

### **学习意义**
- **理论价值**：OSI模型虽然未被完全采用，但提供了清晰的分析框架
- **实践价值**：TCP/IP模型是实际互联网的基础，理解它是关键
- **工程价值**：分层设计让网络问题可以逐层排查

**实战配置**：
```bash
# 示例：搭建一个简单的家庭网络

# 1. 路由器基础配置
# 登录路由器管理界面：192.168.1.1
# 配置LAN口：192.168.1.1/24
# 配置DHCP：分配192.168.1.100-192.168.1.200
# 配置WAN口：PPPoE拨号

# 2. 计算机 TCP/IP 配置
# Windows
# 控制面板 → 网络和 Internet → 网络和共享中心
# 更改适配器设置 → 属性 → IPv4
# 选择"自动获得 IP 地址"和"自动获得 DNS 服务器地址"

# 3. 测试网络连通性
ping 192.168.1.1    # 测试到网关的连通性
ping 8.8.8.8        # 测试到互联网的连通性
nslookup google.com  # 测试DNS解析

# 4. 查看ARP表
arp -a              # Windows
arp -n              # Linux

# 5. 抓包分析
# 使用 Wireshark 抓取 ping 包，观察：
# - ARP 请求和响应
# - ICMP Echo Request 和 Reply
# - MAC 地址和 IP 地址对应关系
```

- **效果**：能够理解网络分层，看懂网络架构图

**阶段 3：实践配置与故障排查（2-3个月）**

- **目标**：能够配置网络设备，排查常见网络问题
- **核心内容**：

**交换机配置**
```bash
# 华为交换机基础配置示例
# ============================================
# 1. 创建 VLAN
vlan 10
 name Production
vlan 20
 name Office
vlan 30
 name Guest
exit

# 2. 配置接口
interface GigabitEthernet0/0/1
 port link-type access
 port access vlan 10
exit

interface GigabitEthernet0/0/2
 port link-type trunk
 port trunk allow-pass vlan 10,20,30
exit

# 3. 配置管理 IP
interface vlan-interface 1
 ip address 192.168.1.1 255.255.255.0
exit

# 4. 配置 DHCP
dhcp enable
dhcp pool network 10.1.0.0 mask 255.255.255.0
 gateway-list 10.1.0.1
 dns-list 8.8.8.8 8.8.4.4
 lease day 7
exit

# 5. 保存配置
save
```

**路由器配置**
```bash
# 家用/SOHO 路由器配置
# ============================================
Router> enable
Router# configure terminal
Router(config)# hostname MyRouter
Router(config)# interface GigabitEthernet0/0
Router(config-if)# description WAN
Router(config-if)# ip address dhcp
Router(config-if)# no shutdown
Router(config-if)# exit
Router(config)# interface GigabitEthernet0/1
Router(config-if)# description LAN
Router(config-if)# ip address 192.168.1.1 255.255.255.0
Router(config-if)# no shutdown
Router(config-if)# exit

# DHCP 配置
Router(config)# ip dhcp pool LAN
Router(dhcp-config)# network 192.168.1.0 255.255.255.0
Router(dhcp-config)# default-router 192.168.1.1
Router(dhcp-config)# dns-server 8.8.8.8 8.8.4.4
Router(dhcp-config)# lease 7
Router(dhcp-config)# exit
Router(config)# ip domain-lookup source-port GigabitEthernet0/0

# NAT 配置（用于上网）
Router(config)# access-list 1 permit 192.168.1.0 0.0.0.255
Router(config)# ip nat inside source list 1 interface GigabitEthernet0/0 overload

# 保存配置
Router(config)# exit
Router# write memory
```

**故障排查流程**
```
网络故障排查七步法：

1️⃣ 确认问题现象
   - 具体症状：无法上网、网速慢、某些应用无法使用？
   - 影响范围：单台设备、局部网络、全部网络？

2️⃣ 检查物理连接
   - 网线是否插好
   - 设备指示灯是否正常
   - 无线信号是否足够

3️⃣ 检查 IP 配置
   - 是否获取到正确的 IP 地址
   - 子网掩码是否正确
   - 网关地址是否正确

4️⃣ 检查连通性
   - ping 网关地址（如 192.168.1.1）
   - ping 公网 DNS（如 8.8.8.8）
   - ping 域名（如 google.com）

5️⃣ 检查 DNS
   - nslookup 或 dig 命令
   - 尝试使用 IP 地址访问
   - 检查 DNS 服务器设置

6️⃣ 检查防火墙/安全策略
   - 是否有安全软件拦截
   - 防火墙规则是否阻止连接
   - 杀毒软件是否影响网络

7️⃣ 检查路由器/交换机
   - 设备是否过热
   - 设备是否需要重启
   - 查看设备日志
```

- **效果**：能够独立完成网络设备配置，解决常见网络问题

## 📚 延伸阅读

### **核心概念速查表**

| 概念 | 所在层次 | 说明 |
|------|---------|------|
| **MAC 地址** | 数据链路层 | 网卡物理地址，48位唯一标识 |
| **IP 地址** | 网络层 | 逻辑地址，32位，标识网络位置 |
| **子网掩码** | 网络层 | 标识网络部分和主机部分 |
| **端口** | 传输层 | 16位，标识应用程序 |
| **DNS** | 应用层 | 域名解析系统 |
| **VLAN** | 数据链路层 | 虚拟局域网，隔离广播域 |
| **路由** | 网络层 | 选择数据包传输路径 |
| **NAT** | 网络层 | 网络地址转换 |
| **TCP/UDP** | 传输层 | 传输层协议 |

### **协议对应关系**

| 应用层协议 | 传输层协议 | 说明 |
|-----------|-----------|------|
| HTTP/HTTPS | TCP | 网页浏览 |
| FTP | TCP | 文件传输 |
| SMTP | TCP | 邮件发送 |
| DNS | UDP | 域名解析 |
| DHCP | UDP | 自动配置 |
| SSH | TCP | 远程登录 |
| RTP | UDP | 实时传输（语音/视频） |
