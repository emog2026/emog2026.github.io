## 📌 一句话总结

超100TB教育资源库，涵盖从幼儿园到大学的全套学习资料

## 🎯 它是做什么的？

edu-knowlege 是一个"教育资源大宝库"。想象一下：

- 你想给孩子找学而思数学课 → 这里整理了小学到高中的全套课程
- 你需要考研/考公资料 → 这里收集了各种机构和名师的备考材料
- 你想学中医/编程/跨境电商 → 这里有相关课程、书籍、视频教程

它通过 GitHub 组织资源，实际内容托管在 doc.869hr.uk，目前拥有超过 100TB 的资源，包括教育课程、影视、纪录片、音乐、书籍、健身健康等多个领域。

涵盖机构包括：学而思、万维、猿辅导、作业帮等知名教育平台。

## 🔑 核心概念解读

### 资源索引库
- **专业说**：通过 GitHub README 提供资源的分类索引和访问链接
- **通俗说**：像图书馆目录——告诉你有什么书、在哪能找到，但书存在别的仓库

### 分布式资源托管
- **专业说**：核心内容存储在外部服务器，GitHub 仅作为索引和元数据
- **通俗说**：像外卖平台——你在 APP 上下单看菜单，但实际饭菜在餐厅做

### 教育机构资源整合
- **专业说**：汇集多个教育机构的课程资料到统一入口
- **通俗说**：像视频网站的聚合播放器——把爱奇艺、腾讯、优酷的内容整合到一个列表

### 场景 1：家长为孩子找学习资源

### 场景 2：大学生考研/考公备考

- **痛点**：需要多机构资料（新东方、中公、华图），但购买成本高
- **方案**：利用项目的教育资源分类获取备考材料
- **具体步骤**：

### 场景 3：成人学习新技能（编程/跨境电商/自媒体）

- **痛点**：网上教程零散，买课程怕踩坑
- **方案**：先通过项目资源试学，再决定是否付费深入学习
- **具体步骤**：
  ```bash

  # - AI相关知识（提示词、教程、视频教程）

  # - 自媒体相关（流量玩法、获客、转化、变现）

  curl https://doc.869hr.uk | grep -i "跨境电商\|AI\|自媒体"
  
  # 3. 选择感兴趣的课程下载学习
  ```
- **效果**：免费试学避免踩坑，找到适合的学习路径
