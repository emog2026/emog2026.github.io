## 一、成为网络工程师的完整学习路线

### 1. 核心知识体系（按顺序打通）

| 层次 | 你要掌握的概念 | 在组网中的体现 |
|------|----------------|----------------|
| 第1层 物理 | 网线（双绞线）、光纤、RJ45/RJ11、速率(百兆/千兆/2.5G) | 选什么线、面板怎么打 |
| 第2层 数据链路 | MAC地址、ARP、交换机、VLAN、STP | 局域网怎么通、怎么隔离 |
| 第3层 网络 | IP地址、子网划分、路由、网关、ICMP | 不同网段怎么互通 |
| 第4层 传输 | TCP/UDP、端口、NAT | 上网、端口转发 |
| 第7层 应用 | DNS、DHCP、HTTP | 解析域名、自动分配IP |

> 这就是 **OSI 七层模型** 和 **TCP/IP 四层模型**。网络工程师的本质就是"在每一层定位故障在哪一层"。

### 2. 推荐认证路径

- **入门**：华为 **HCIA-Datacom** 或 思科 **CCNA** —— 选一个即可，国内就业华为更吃香。
- **进阶**：华为 **HCIP-Datacom** 或 思科 **CCNP**。
- **专家**：华为 **HCIE** 或 思科 **CCIE**。

### 3. 实验环境搭建

从 0 起步最重要的一步——**先在模拟器里把命令敲熟，再去碰真机**：

| 模拟器 | 适合 | 说明 |
|--------|------|------|
| **华为 eNSP** | 学华为命令 | 免费官方模拟器，国内首选 ⭐ |
| **Cisco Packet Tracer** | 学思科命令 | 思科官方，简单易上手 |
| **EVE-NG / GNS3** | 进阶/真实镜像 | 能跑真实系统镜像，接近真机 |
| **VMware/VirtualBox + OpenWrt** | 家庭软路由 | 软路由组网必练 |

### 4. 分阶段学习计划（约 3~6 个月达到"能独立组网"）

| 阶段 | 时长 | 目标 | 产出 |
|------|------|------|------|
| **第1阶段·地基** | 2周 | OSI、IP/子网划分、ARP、DHCP、DNS、NAT 概念 | 能口述"上网报文怎么走" |
| **第2阶段·实验** | 3周 | eNSP/PT 装好，敲熟交换(VLAN/STP)+路由(静态) | 模拟器内独立搭通一个小网 |
| **第3阶段·家庭组网** | 1~2周 | 真机：单路由→交换扩展→Mesh→AC+AP→软路由 | 自己家/朋友家实战 ⭐本次重点 |
| **第4阶段·小公司组网** | 2周 | 网关+二层/三层交换+VLAN隔离+无线+外网接入 | 能给10~50人公司出方案 |
| **第5阶段·中型公司** | 3周 | 核心层/汇聚层/接入层架构、OSPF、ACL、可靠性 | 能设计多部门、多楼层网络 |
| **第6阶段·冲刺认证** | 持续 | 刷 HCIA/CCNA 题库 + 实验强化 | 拿证 |

## 二、网络工程核心基础（从 0 讲起）

### 1. IP 地址与子网划分（最重要的基本功）

家用最常见的网段：`192.168.1.0/24`

```
192.168.1.0/24  拆解：
   192.168.1.0   → 网络号（代表"这个网段"，不能分配给设备）
   192.168.1.1   → 通常做网关（路由器地址）
   192.168.1.2 ~ 192.168.1.254 → 可用给设备
   192.168.1.255 → 广播地址（不能用）
   子网掩码：255.255.255.0   （就是 /24）
```

**关键三件套**（设备上网必须配齐）：
- **IP 地址**：设备的门牌号
- **子网掩码**：划定你住哪个小区
- **默认网关**：出了小区走哪个门（路由器LAN口IP）
- **DNS**：114.114.114.114、223.5.5.5（阿里）、8.8.8.8（谷歌）

**私网地址段（必须记住）：**
```
A类：10.0.0.0    ~ 10.255.255.255     (10/8)
B类：172.16.0.0  ~ 172.31.255.255     (172.16/12)
C类：192.168.0.0 ~ 192.168.255.255    (192.168/16)
```

### 2. 必会的诊断命令（排查故障的第一工具）

**Windows（CMD / PowerShell）：**
```bash
ipconfig /all          # 看本机IP、网关、DNS、MAC，最常用
ipconfig /release      # 释放IP
ipconfig /renew        # 重新获取IP（DHCP续租）
ping 192.168.1.1       # 测试到网关通不通（先测这步！）
ping 8.8.8.8           # 测试到外网IP通不通（判断是否DNS问题）
ping www.baidu.com     # 测试域名解析通不通
tracert 8.8.8.8        # 跟踪路由，看报文走到第几跳断了
arp -a                 # 查看本机ARP表（IP↔MAC对应）
nslookup www.baidu.com # 手动测DNS解析
netstat -ano           # 查看本机端口连接
route print            # 查看本机路由表
```

**Linux / macOS：**
```bash
ip addr                # 看IP（替代老的 ifconfig）
ip route               # 看路由表
ping -c 4 8.8.8.8      # ping 4次后停止
traceroute 8.8.8.8     # 跟踪路由（Linux命令名）
ss -tlnp               # 查看监听端口（替代 netstat）
```

> **故障排查黄金顺序**：`ping 网关 → ping 8.8.8.8 → ping 域名`。一步不通就定位到一层。

### 3. OSI 模型速记

```
7. 应用层   Application   HTTP、DNS、DHCP   —— 你看到的
6. 表示层   Presentation  加密、编码        ｜
5. 会话层   Session       建立会话          ｜ 合称"上三层"
4. 传输层   Transport     TCP、UDP          —— 端口、可靠传输
3. 网络层   Network       IP、ICMP          —— 路由器工作在这层
2. 数据链路层 Data Link   MAC、ARP、VLAN    —— 交换机工作在这层
1. 物理层   Physical      网线、电信号       —— 比特流

口诀（从下往上）："物、数、网、传、会、表、应"
```

## 三、家庭组网实战（第一站，重点）

### 家庭组网方案对比（先选型）

| 方案 | 适用 | 成本 | 难度 | 评价 |
|------|------|------|------|------|
| **A 单路由器** | 小户型 | 低 | ⭐ | 够用就行 |
| **B 路由器+交换机** | 预埋网线、多房间 | 低 | ⭐⭐ | 有线党首选 |
| **C Mesh组网** | 大户型、无网线 | 中 | ⭐⭐ | 简单省事 |
| **D AC+AP** | 新房预埋网线 | 中高 | ⭐⭐⭐ | 体验最好、最专业 |
| **E 软路由+AP** | 折腾党、极客 | 中 | ⭐⭐⭐⭐ | 功能无敌 |

### 方案 A：单路由器（入门，先吃透原理）

**拓扑：**
```
[光猫] --网线--> [路由器WAN口] ... 路由器LAN口/WiFi ... [手机/电脑]
```

**关键操作（家用路由器 Web 界面）：**

1. **连接方式二选一（非常重要）：**
   - **方式① 路由模式（最常见）**：光猫LAN → 路由器WAN口。光猫拨号或路由器拨号。
   - **方式② AP模式（桥接）**：光猫LAN → 路由器LAN口（注意是LAN口！），关闭路由器DHCP。光猫当主路由，路由器只做无线。光猫性能差时不推荐。

2. **进入管理界面**：浏览器访问 `192.168.1.1` 或 `192.168.0.1` 或 `192.168.31.1`（小米），账号密码在路由器底部贴纸。

3. **必须配置的核心项：**
   - **WAN口**：PPPoE拨号（输宽带账号密码）或 动态IP（DHCP，光猫已拨号时）
   - **LAN口IP**：如 `192.168.31.1`（建议改成非常见网段，避免和光猫冲突）
   - **DHCP服务**：开启，分配范围如 `192.168.31.100~192.168.31.200`
   - **WiFi**：SSID（名字）、密码、加密方式选 **WPA2-PSK** 或 **WPA3**，2.4G/5G分开设

**常见问题速查：**
- 能上QQ打不开网页 → **DNS问题**，手动设DNS为 `223.5.5.5`
- 下载满速但网页慢 → 换DNS、检查MTU
- 设备频繁掉线 → WiFi信道拥挤，用"WiFi分析仪"App换信道

### 方案 B：路由器 + 交换机（有线扩展，最实用）

**拓扑：**
```
[光猫] → [主路由器] → [交换机] → 各房间网口 → [电脑/电视/NAS]
                    ↘ WiFi覆盖主区域
```

**设备选择：**
- **傻瓜交换机**（无管理功能，即插即用）：TP-Link、水星，5口/8口，几十块。家用**足够**。
- **网管型交换机**（支持VLAN）：为后续学习预留，TP-Link SG2008等，可玩VLAN。

**配置：傻瓜交换机无需配置**，通电插线即用。所有口同属一个局域网。

**网管型交换机的第一个VLAN实验（为进阶铺路）：**
这里用通用CLI演示（不同品牌命令略异，华为/思科在后面阶段专门讲）：
```
# 进入配置（示例：Web管理型交换机典型操作）
enable                          # 进入特权模式
configure terminal              # 进入全局配置
vlan 10                         # 创建VLAN 10（如"家庭设备"）
 name HOME
vlan 20                         # 创建VLAN 20（如"IoT物联网"）
 name IOT
interface gigabitEthernet 0/1   # 进1号口
 port link-type access          # 设为接入口
 port default vlan 10           # 划入VLAN10
exit
```
> 在家庭场景，VLAN的价值是**隔离**：把摄像头、智能家居放VLAN20，和你的电脑(VLAN10)隔离，避免摄像头被黑后横向攻击内网。这是"网络思维"的开始。

### 方案 C：Mesh 组网（无线扩展，无需布线）

**原理**：多个路由器组成一个 mesh 网络，统一SSID，设备自动切换到信号最好的节点。

**拓扑：**
```
[主节点] --(有线回程，最佳)--> [子节点1] --(无线回程)--> [子节点2]
```

**关键概念：回程**
- **有线回程**（推荐）：主子节点用网线连接，性能最好、最稳定。
- **无线回程**：节点间用WiFi传数据，会占用一半带宽，效果打折扣。

**配置（以主流Mesh路由器为例）：**
1. 主节点正常设置上网。
2. 子节点**靠近**主节点通电。
3. Web/App里点"添加Mesh节点"，自动同步WiFi名称密码。
4. 配好后把子节点搬到目标位置。

**选购建议**：同品牌同型号组Mesh，避免混搭；优选支持 WiFi 6 (802.11ax)、三频（专用回程频段）的。

### 方案 D：AC + AP（专业级，新房首选）⭐

这是家庭组网里**最专业、体验最好**的方案，也是迈向企业组网的过渡。

**原理**：
- **AC（Access Controller，无线控制器）**：统一管理所有AP，下发配置。
- **AP（Access Point，无线接入点）**：只负责发射WiFi信号，不做路由、不做NAT。
- 主路由 + AC + 多个AP，AP通过 **PoE（网线供电）** 用一根网线解决供电和数据。

**拓扑：**
```
[光猫] → [主路由/网关] → [PoE交换机] --网线供电+数据--> [AP1/AP2/AP3...]
                            （AC功能可集成在路由器/交换机里）
```

**为什么是预埋网线才适合？** 因为每个AP都需要一根网线回到弱电箱，必须装修时预埋。

**典型设备组合（华为/TP-Link企业级常见）：**
- 主网关/路由（集成AC功能）：如华为 AirEngine 5760、TP-Link易展AC+AP套装
- PoE交换机：给AP供电
- 面板AP：装在房间网口面板位置，美观
- 吸顶AP：装在客厅天花板，覆盖大

**配置流程（Web，以企业级AC为例）：**
1. 主路由配WAN口上网、配LAN网段。
2. AP接PoE交换机，AC自动发现AP（CAPWAP协议）。
3. 在AC上创建"SSID配置模板"，统一下发WiFi名称密码。
4. 所有AP发射**同一个WiFi**，设备无感漫游。

**核心命令初体验（华为AC典型CLI，为后面铺路）：**
```
system-view                              # 进入系统视图
wlan                                     # 进入WLAN视图
ssid-profile name HOME_WIFI              # 创建SSID模板
 ssid HOME                               # WiFi名称
security-profile name HOME_SEC           # 创建安全模板
 security wpa2 psk pass-phrase YourPWD   # WPA2密码
vap-profile name HOME_VAP                # 创建VAP(虚拟AP)模板
 service-vlan vlan-id 10                 # 业务VLAN
 ssid-profile HOME_WIFI
 security-profile HOME_SEC
ap-group name default                    # 进入AP组
 vap-profile HOME_VAP wlan 1 radio all   # 下发到所有AP的射频
```
> 看不懂没关系——这是"企业级思维"的预告。到小公司阶段会逐行讲。

### 方案 E：软路由 + AP（极客方案，功能最强）

**原理**：用一台小主机（x86）跑专业路由系统（如 **OpenWrt**、**iKuai（爱快）**、**ROS**），性能远超家用路由器，插件无限（去广告、科学上网、流量监控、多线负载均衡……），无线由独立AP负责。

**拓扑：**
```
[光猫] → [软路由(2~4网口)] → [PoE交换机] → [AP]
                          → [NAS/交换机] → 有线设备
```

**OpenWrt 入门配置命令（真命令行，干货）：**

OpenWrt 用 **UCI**（统一配置接口）管理配置，也可以直接改文件。

```bash
# 1. 配置WAN口（PPPoE拨号）
uci set network.wan=interface
uci set network.wan.proto='pppoe'
uci set network.wan.username='宽带账号'
uci set network.wan.password='宽带密码'
uci set network.wan.ipv6='auto'

# 2. 配置LAN口（网关地址）
uci set network.lan.ipaddr='192.168.10.1'

# 3. 配置DNS
uci set network.lan.dns='223.5.5.5 114.114.114.114'

# 4. 应用所有配置（关键！UCI改完必须commit+reload）
uci commit network
/etc/init.d/network reload
```

也可以直接编辑 `/etc/config/network`：
```
config interface 'lan'
    option proto 'static'
    option ipaddr '192.168.10.1'
    option netmask '255.255.255.0'

config interface 'wan'
    option proto 'pppoe'
    option username '宽带账号'
    option password '宽带密码'
```

**软路由常用诊断命令：**
```bash
ifconfig | ip addr       # 查接口IP
route -n                 # 查路由表
ping 223.5.5.5           # 测外网
logread                  # 看系统日志（排错神器）
uci show network         # 显示当前网络配置（全量）
```

## 四、家庭组网小结与建议

1. **新房装修**：一定 **全屋预埋超六类网线**（Cat6A），每个房间至少一根回弱电箱。这是后悔成本最高的决定。
2. **预埋了网线** → 直接上 **AC+AP 或 软路由+AP**，一步到位。
3. **没法布线** → **Mesh组网**，能用有线回程就别用无线回程。
4. **极小户型** → 一个好路由器搞定。
