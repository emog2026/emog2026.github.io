📌 **一句话总结**：本地运行的 AI 短剧创作工具，从故事到成片一站式完成，数据完全私有。

🎯 **它是做什么的？**

LocalMiniDrama 是一个开源的本地 AI 短剧和漫剧生成工具。你可以把它想象成一个"个人短视频工作室"：

- **输入**：一个故事梗概（比如"现代都市爱情剧"）
- **输出**：完整的短视频剧集（包含角色、场景、分镜、配音）

**核心工作流程：**
1. 故事生成 → AI 自动生成多集剧本
2. 角色生成 → AI 提取角色并生成角色形象图  
3. 场景生成 → 从剧本自动提取场景，生成背景图
4. 分镜生成 → 按集自动生成分镜脚本（含景别、运镜、台词）
5. 图片/视频生成 → 逐镜生成静帧图与视频片段
6. 合成视频 → 所有的分镜视频自动合成为完整剧集文件

**最大特点：**
- 🎯 **完全本地运行** - 数据不上云端，隐私绝对安全
- 💰 **无订阅费** - 接入你自己的 AI API，按量付费
- 🔧 **高度可定制** - 开源可二次开发，支持多家 AI 服务商

🔑 **核心概念解读**

**AI 短剧工作流**
- 专业说：从文本输入到视频输出的自动化流程
- 通俗说：就像一个全自动的"剧组" - 你给出故事梗概，它自动帮你完成编剧、选角、布景、拍摄、剪辑所有工作

**分镜脚本**
- 专业说：描述每个镜头的景别、运镜、台词、时间的文本
- 通俗说：类似连环画的"画面说明" - 告诉 AI 每个镜头该拍什么、怎么拍

**参考图机制**
- 专业说：在生成新画面时提供风格和角色一致性的参考图像
- 通俗说：就像给摄影师看"样片" - 确保不同镜头里的主角长得一样、场景风格统一

💡 **切实可落地的例子**

**场景 1：个人内容创作者**
- **痛点**：想制作 AI 短剧但担心素材泄露，不愿使用在线平台
- **解决方案**：使用 LocalMiniDrama 本地生成，所有角色和场景数据都在自己的电脑上
- **具体实现步骤**：
  1. 下载 exe 文件（推荐"本地短剧助手 x.x.x.exe"标准版）
  2. 安装后打开软件，在"AI 配置"页面填写你的阿里云或火山引擎 API Key
  3. 新建项目，输入故事梗概（如"现代职场爱情剧，轻松搞笑风格"）
  4. 点击"一键生成视频"，软件自动完成从剧本到成片的全部流程
- **效果**：每周节省 10+ 小时手动制作时间，且素材完全私有

**场景 2：小型工作室批量生产**
- **痛点**：需要批量生产短剧内容，云端工具订阅费用太高
- **解决方案**：使用本地版本 + 按量付费的 API，大幅降低成本
- **具体实现步骤**：
  ```bash
  # 开发模式运行（支持自定义配置）
  git clone https://github.com/xuanyustudio/LocalMiniDrama.git
  cd LocalMiniDrama/backend-node
  npm install
  cp configs/config.example.yaml configs/config.yaml
  # 编辑 config.yaml，配置你的 API 密钥
  npm start  # 启动后端（默认端口 5679）
  
  cd ../frontweb
  npm install
  npm run dev  # 启动前端（默认端口 3013）
  ```
  访问 `http://localhost:3013`，即可开始批量创作
- **效果**：相比云端 SaaS 工具，每月节省数千元订阅费，且可同时处理多个项目

**场景 3：开发者二次开发定制**
- **痛点**：现有 AI 短剧工具功能不符合特定业务需求
- **解决方案**：基于 LocalMiniDrama 开源代码进行定制开发
- **具体实现步骤**：
  1. Fork 项目到自己的 GitHub 账号
  2. 修改前端 `frontweb/src/` 中的 Vue 组件，定制你需要的 UI
  3. 在后端 `backend-node/src/services/` 添加新的 AI 服务商支持
  4. 构建自己的桌面版本：
  ```bash
  cd desktop
  npm install
  npm run build  # 生成定制版 exe 安装包
  ```
- **效果**：完全掌控技术栈，可集成内部 AI 模型或添加特定业务功能

👥 **适合谁用？**

✅ 内容创作者需要批量生产 AI 短剧/漫剧
✅ 隐私敏感用户（素材不能上传云端）
✅ 开发者（基于此项目进行二次开发）
✅ 入门探索者（低成本体验 AI 视频赛道）
❌ 只需要偶尔生成一两张图片的用户（工具太重）
❌ 不愿折腾技术配置的用户（需要配置 API 密钥等）

⚠️ **注意事项**

- **费用**：软件本身免费开源，但需要接入自己的 AI API（按量付费）
- **学习曲线**：⭐⭐⭐☆☆（需要理解 AI API 配置和短剧制作基本概念）
- **支持的视频模型**：火山引擎豆包 Seedance、即梦、可灵 Kling、Vidu、Google Veo 等多家服务商
- **替代方案**：Kino 视界（云端为主，非开源）、Filmaction AI（SaaS 部分付费）
- **最新版本亮点**：支持 Seedance 2.0 多图参考视频生成、分镜全能模式、AI 并发生成等高级功能
