## 🎯 它是做什么的？

**BongoCat** 是一个开源的**桌面宠物软件**，会在你的屏幕上放一只可爱的猫咪，它会跟随你的鼠标移动并对你的操作做出反应。

**核心功能**：
- **鼠标跟随**：猫咪会追踪鼠标位置移动
- **点击动画**：左键/右键点击时有独特的动画反馈
- **互动反馈**：猫咪会对你的操作做出可爱的反应
- **轻量级**：占用资源少，不影响日常使用
- **跨平台**：支持 Windows、macOS、Linux

**它解决了什么问题？**
- 🔹 工作学习太枯燥，需要一点可爱的陪伴
- 🔹 想要一个不占空间的桌面宠物
- 🔹 需要一个小助手缓解压力
- 🔹 想让桌面更有生机

## 🔑 核心概念解读

**Desktop Pet（桌面宠物）**
- 专业说：一个常驻桌面的轻量级交互式图形程序
- 通俗说：像在屏幕上养了一只小猫，它会在你工作时陪着你

**Mouse Tracking（鼠标追踪）**
- 专业说：实时监听鼠标位置事件并更新角色坐标
- 通俗说：鼠标往哪移，猫咪就往哪跑

**Click Animation（点击动画）**
- 专业说：监听鼠标点击事件并触发对应的动画状态
- 通俗说：点击鼠标时，猫咪会做特定动作（比如跳跃、挥手）

**Resource-Saving（省资源）**
- 专业说：采用轻量级渲染，CPU 和内存占用极低
- 通俗说：就算电脑配置低，也能流畅运行

## 💡 切实可落地的例子

### 场景 1：上班族 / 学生党

**痛点**：对着电脑一整天，心情越来越烦躁

**方案**：养一只桌面猫咪，工作时陪伴

**具体步骤**：
```bash
# 下载 BongoCat
# 访问 GitHub Releases 下载对应系统的安装包

# Windows: 下载 BongoCat-win32-x64-xxx.zip
# macOS: 下载 BongoCat-darwin-x64-xxx.dmg
# Linux: 下载 BongoCat-linux-x64-xxx.AppImage

# 解压后直接运行
./BongoCat  # Linux/macOS
BongoCat.exe  # Windows

# 或者使用源码编译
git clone https://github.com/ayangweb/BongoCat.git
cd BongoCat
npm install
npm start
```

**效果**：
- 工作累了一低头，屏幕上有只小猫陪着你
- 点击鼠标时猫咪会互动，瞬间治愈
- 几乎不占内存，不影响工作

### 场景 3：开发者 / DIY 爱好者

**痛点**：想自定义桌面宠物，添加自己的角色

**方案**：使用源码修改角色和动画

**具体步骤**：
```bash

#   ├── assets/       # 资源文件（图片、动画）
#   ├── main.js       # 主程序入口
#   ├── renderer.js   # 渲染逻辑
#   └── config.js     # 配置文件

# 替换猫咪资源
# 1. 准备自己的猫咪图片（PNG 格式，透明背景）
# 2. 替换 src/assets/ 下的对应文件
# 3. 重新运行
npm install
npm start
```

**效果**：
- 可以换成自己设计的角色
- 可以添加更多互动动画
- 完全个性化定制
