🎯 **它是做什么的？**

**wx_channels_download** 是一个**微信视频号下载工具**，由开发者 ltaoo 用 Go 语言开发，在 GitHub 上获得了 6.5k+ stars。

简单来说，它能做三件事：

1. **给微信 PC 端加下载按钮**：在视频号视频旁边直接显示下载按钮
2. **在线解析视频链接**：通过分享链接获取视频下载地址
3. **多质量选择**：支持下载不同清晰度的视频

想象一下：
- 你在微信 PC 端刷视频号，看到喜欢的视频
- 直接点击新出现的"下载"按钮
- 视频就保存到本地了，不需要任何复杂的操作

🔑 **核心概念解读**

**证书安装（SSL Certificate）**
- 专业说：在系统安装自签名证书，用于拦截 HTTPS 流量
- 通俗说：像给"快递检查员"发一个通行证，让他能检查加密的包裹（网络流量）

**中间人代理（MITM Proxy）**
- 专业说：拦截并转发客户端和服务器之间的网络请求
- 通俗说：像"快递中转站"——快递从寄件人到收件人必须经过这里，你可以检查并修改包裹内容

**网络流量嗅探（Network Sniffing）**
- 专业说：监控和分析网络数据包，提取有用的信息
- 通俗说：像"监听电话"——你能听到两个人在说什么，从中找到你需要的地址、密码等信息

💡 **切实可落地的例子（3 个场景）**

**场景 1：内容创作者素材收集**
- **痛点**：看到视频号上好的创意、音乐、转场效果，想保存下来做参考
- **解决方案**：使用 wx_channels_download 直接下载视频到本地，在剪辑软件中逐帧分析
- **具体实现步骤**：
```bash
# 1. 下载构建包
# 访问 https://github.com/ltaoo/wx_channels_download/releases
# 下载最新版本（如 v260607）的 Windows 或 macOS 版本

# 2. 以管理员身份运行
# Windows：右键"以管理员身份运行"
# macOS：sudo 命令运行

# 3. 首次运行会自动安装证书，点击"是"确认

# 4. 等待终端提示"代理服务启动成功"

# 5. 打开微信 PC 端，浏览视频号
# 6. 点击视频下方的"下载"按钮
# 7. 视频保存到程序的 downloads 文件夹
```
- **效果**：快速收集素材库，用于学习和创作参考

---

**场景 2：视频备份归档**
- **痛点**：自己发布的视频号内容，想定期备份到本地硬盘，防止平台下架或账号异常
- **解决方案**：批量下载自己发布的视频，建立本地备份库
- **具体实现步骤**：
```bash
# 1. 启动 wx_channels_download（同场景1）

# 2. 在微信 PC 端进入自己的视频号主页

# 3. 依次点击每个视频，点击下载按钮

# 4. 定期整理下载的视频到备份文件夹
#    例如：D:\视频号备份\2026年6月\

# 5. 使用视频管理软件（如 Plex、Emby）建立本地视频库
```
- **效果**：建立个人视频档案，确保内容安全

**场景 3：在线解析获取视频链接**
- **痛点**：朋友分享了一个视频号链接，但你没安装下载工具，只想快速获取视频
- **解决方案**：使用项目提供的在线解析服务
- **具体实现步骤**：
```bash
# 1. 复制微信视频号分享链接
#    格式如：https://weixin.qq.com/sph/Axv548mzBF

# 2. 打开在线解析页面
#    浏览器访问：https://sph.litao.workers.dev/

# 3. 粘贴分享链接，点击"解析"

# 4. 获取视频下载链接，可直接下载或复制链接到下载工具
```
- **效果**：无需安装任何软件，快速获取视频
