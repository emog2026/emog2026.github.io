## 📌 装机

**U盘启动制作工具：[Rufus](https://rufus.ie/zh/)**

[系统镜像](https://hellowindows.cn/)，包括原版windows ISO: Windows XP、Windows 7、Windows 8、Windows10、Windows11、Server 2012、Server 2019、Server 2022

[Office](https://hellowindows.cn/)：Office2003、Office2007、Office2019、Office2021、Office2024

[Microsoft Activation Scripts (MAS)](https://pan.xunlei.com/s/VOqAsTjsfla84YuCIxDPR6cPA1?pwd=gf9w): 激活windows、office，批处理脚本，双击即可运行。

[windows多功能工具](https://github.com/winsiderss/systeminformer)，监控 CPU、内存、磁盘、网络、服务、线程、句柄等全方位系统资源，遇到”文件删除不了”可找对应进程杀掉，可查看正在运行占用的端口。

[windows 磁盘大文件查找](https://github.com/qarmin/czkawka)，想清理C盘时候用到

[windows Notepad++](https://github.com/notepad-plus-plus/notepad-plus-plus)，文本编辑器

[windows 调节显示器亮度](https://github.com/emoacht/Monitorian)

[加速 git clone 拉取速度](https://github.com/creazyboyone/FastGithub/releases)，支持windows、linux、macos，不要挂代理

[clash verge](https://www.clashverge.dev/install.html#__tabbed_1_1)，支持windows、linux、macos

[沉浸式翻译](https://www.immersivetranslate.net/)，英文网站看不习惯，整个页面一键翻译成中文

[shadowsocks 客户端](https://mailsoftware.org/archives/1794)

[飞书文档](https://www.feishu.cn/)，只要能网页登录，知识记录，手机、电脑共享。

[windows 优化器](https://github.com/hellzerg/optimizer/releases)，【所有变更重启电脑后生效】禁止Windows Update自动更新、禁用小娜Cortana、禁用新闻和兴趣、任务栏靠左对齐、隐藏任务栏天气、禁用休眠、删除启动项、启用经典右键菜单。
