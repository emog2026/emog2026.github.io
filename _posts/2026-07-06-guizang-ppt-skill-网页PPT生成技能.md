🎯 **它是做什么的？**

Guizang PPT Skill（歸藏 PPT 技能）是一个给 AI Agent 用的"网页 PPT 制作能力包"。你可以理解为：**给 Claude Code 这类 AI 助手装上了一个"专业设计师大脑"**，让 AI 懂得怎么把一篇文章、一份 Markdown、一个产品分析，自动排版成一份可以直接浏览器打开的精美演示文稿。

传统的 PPT 制作痛点：
- 用 PowerPoint/Keynote 手动拖拽排版，调整字号、对齐、配色很费时间
- AI（比如 ChatGPT 网页版）能写文字，但不懂得怎么排版出"高级感"，生成的 PPT 往往很丑
- 想要统一风格的多平台封面（公众号、小红书、视频号），每张都要重新设计

这个 Skill 解决的问题：
- 把内容丢给 AI，AI 会按**预设的专业版式**自动生成单文件 HTML 演示稿
- 内置两套设计语言：**电子杂志风**（像 Monocle 杂志，适合叙事）和**瑞士国际主义风**（网格化、高饱和色，适合事实/产品/分析表达）
- 还能顺便生成 PPT 配图和多平台封面（公众号 21:9、小红书 3:4、视频号横版等）

**和同类产品的区别**：
- 对比 **Gamma / Tome**（在线 AI PPT 工具）：这个是装在本地 AI Agent 里的"技能包"，生成的是**单文件 HTML**，没有构建步骤、不需要服务器，可自由修改源码；Gamma 则是在线 SaaS，云端生成、受平台限制。
- 对比 **Slidev / Reveal.js**（代码写 PPT 的框架）：那些需要你自己懂前端、自己写代码；这个是让 **AI 替你写**，你只需要说人话提需求。
- 对比 **AI 生图工具**：那些只解决"配图"问题；这个覆盖**完整链路**——PPT 主体 + 配图 + 多平台封面 + 截图美化。

🔑 **核心概念解读**

**Skill（技能）**
- 专业说：给 AI Agent 扩展能力的结构化工作流包（含 SKILL.md + 模板 + 参考资料）
- 通俗说：就像给手机装一个"专业相机 App"——AI 本身是个通用助手，装上这个技能后，它就突然具备了"做专业网页 PPT"的本事。
- 生活类比：相当于给一个聪明但没学过设计的助手，递上一本《设计师操作手册》+ 一套现成模板。

**HTML PPT（网页演示稿）**
- 专业说：用单个 HTML 文件承载的横向翻页演示文稿，支持键盘/滚轮/触屏操作
- 通俗说：一份能用浏览器直接打开的"网页版 PPT"，双击就能演示，不用装任何软件。
- 生活类比：像一份精美的网页文章，但翻页方式像幻灯片，按 ← → 键或滑动就能一页页看。

**Style A 电子杂志风**
- 专业说：模仿 Monocle 杂志的版式语言，强调叙事感和个人风格
- 通俗说：看起来像一本高端杂志的电子版，有文艺气质、留白多、适合讲故事。
- 生活类比：就像《读者》或《Monocle》杂志的排版搬到屏幕上。

**Style B 瑞士国际主义风**
- 专业说：16 列网格 + 单一高饱和锚点色 + 直角 + 发丝线 + 极致字号对比的版式系统
- 通俗说：极简、克制、信息密度高，大量留白配上一个抢眼的纯色（比如克莱因蓝），看起来非常"高级、专业、国际化"。
- 生活类比：像苹果发布会、国际大牌海报那种"少即是多"的工业感设计。

**锁定版式（Lock Layout）**
- 专业说：正文页只能从 S01 到 S22 这 22 个具名版式中选择，不能临时发明页面结构
- 通俗说：设计师已经帮你把"好版式"穷举好了，AI 只能"填空"不能"乱画"，从而保证美观。
- 生活类比：就像乐高套装里的固定拼法图纸，按图纸拼一定好看，不能自己瞎发挥。

💡 **切实可落地的例子**

**场景 1：自媒体创作者 / 个人分享**
- 痛点：写了一篇万字长文，线下要做一场分享，但不会设计 PPT，用 PowerPoint 拼出来的很土。
- 方案：用 Guizang PPT Skill，让 AI 把文章自动转成杂志风网页 PPT。
- 具体步骤：
  ```bash
  # 1. 一行命令安装技能（需要 Node.js 环境）
  npx skills add https://github.com/op7418/guizang-ppt-skill --skill guizang-ppt-skill

  # 或者把这段话直接发给有 shell 权限的 AI Agent：
  # 帮我安装 guizang-ppt-skill。请把
  # https://github.com/op7418/guizang-ppt-skill
  # 克隆到 ~/.claude/skills/guizang-ppt-skill
  ```
  ```text
  # 2. 安装后，把你的文章粘贴给 AI，直接说：
  帮我把这篇 Markdown 做成杂志风演讲 PPT。
  ```
- 效果：几分钟得到一份单文件 HTML PPT，浏览器双击打开即可演示，按 ← → 翻页，按 ESC 看全部索引。线下分享、发链接给朋友都很方便。

**场景 2：创业公司 / 产品经理（Demo Day、产品发布）**
- 痛点：要做产品发布或 Demo Day 的演讲 PPT，需要专业、克制、突出数据和事实，但不能花太多时间在设计上。

  ```bash
  node scripts/validate-swiss-deck.mjs path/to/index.html

  # 需要切换锚点色（如克莱因蓝→安全橙）：
  # 只需修改 template-swiss.html 开头的主题变量，其他样式自动跟随
  ```
- 效果：22 种锁定版式 + 强校验器保证排版不出错，KPI 大字报、对比图、流程图都能直接套用，演讲时看起来像专业设计团队出品。按 `B` 还能切到低性能静态模式（关闭 WebGL 动画），在配置一般的电脑上也能流畅演示。

**场景 3：内容运营 / 品牌团队（多平台封面矩阵）**
- 痛点：同一篇内容要在公众号、小红书、视频号发，每个平台封面尺寸不同（21:9、3:4、16:9），设计师每张都要单独做，效率低且风格不统一。
- 方案：基于同一份 PPT 的视觉规则，一次性生成多平台封面。
- 具体步骤：
  ```text
  # 做完 PPT 后，对 AI 说：
  基于这份 PPT 的主题，做两张封面：
  公众号 21:9 头图和 1:1 分享卡，视觉保持一致。

  # 或者直接生成小红书 / 视频号封面：
  基于这份 PPT 的核心观点，生成一张小红书 3:4 封面。
  把这张产品截图重新设计成适合 PPT 的 16:10 配图。
  ```
  ```bash
  # 封面规格对照：
  # 公众号头图 21:9 | 公众号分享卡 1:1
  # 小红书封面 3:4 | 视频号横版 16:9
  # 截图再设计 16:10
  ```
- 效果：一套视觉规则覆盖所有平台，封面风格统一、关键词一致，省去逐个平台手动设计的重复劳动。配图不带页脚标题角标，可直接嵌入使用。

👥 **适合谁用？**

✅ 经常做**线下分享、行业内部讲话、私享会**的人
✅ **AI 产品发布、Demo Day** 需要专业演讲稿的创业者/产品经理
✅ 有**强烈个人风格**、想做"叙事型"演讲的内容创作者
✅ 已经在用 **Claude Code / Codex / Cursor** 等 AI Agent 工作流的开发者
✅ 需要批量产出**统一风格多平台封面**的运营/品牌团队

❌ 需要**大段表格数据**展示的人（信息密度不够，表格排版是弱项）
❌ 做**培训课件**（需要海量文字密度，这套美学偏克制留白）
❌ 需要**多人协作编辑**的团队（生成的是静态 HTML，不像在线文档能实时协同）
❌ 只用**普通 ChatGPT 网页版**、没有本地文件系统的用户（没有文件读写和浏览器预览，AI 很难稳定生成完整 deck）
❌ 想要 **PPTX 格式**交付的人（核心交付是 HTML，PPTX 需要自己二次转换）

⚠️ **注意事项**

- **付费/免费**：完全免费，开源协议 **AGPL-3.0**（注意：AGPL 要求你修改后的版本若作为网络服务提供，也必须开源）
- **运行环境**：必须在 **Claude Code / Codex / Cursor** 等支持文件读写和 shell 命令的 AI Agent 环境中运行，普通聊天机器人不行
- **学习曲线**：⭐⭐⭐☆☆（中难度）—— 会用 AI Agent 就能上手，但想调出最佳效果需要理解"杂志风 vs 瑞士风"的区别、熟悉 22 种版式、以及掌握"需求澄清 7 问"（风格/受众/时长/素材/图片需求/主题色/硬约束）
- **颜色限制**：**不允许自定义 hex 颜色值**，只能从预设主题里选（Style A 5 套电子墨水主题 + Style B 4 套瑞士锚点色）—— 这是有意为之，防止自由选色破坏整体风格
- **导出限制**：核心交付是 HTML，不能直接导出 PPTX；可以用浏览器演示、截图、录屏，或把 HTML 当视觉稿再转换
- **替代方案**：
  - **Gamma / Tome**：在线 AI PPT，开箱即用但受平台限制、需付费
  - **Slidev**：Vue 驱动的代码 PPT 框架，需自己写代码
  - **Reveal.js**：经典 HTML 演示框架，需手动编写
  - **Microsoft Designer / Copilot**：微软生态内的 AI 设计工具
