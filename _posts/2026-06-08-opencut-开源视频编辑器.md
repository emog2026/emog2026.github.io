## 📌 一句话总结

免费开源的视频编辑工具，CapCut 的替代品，支持网页、桌面和移动端。

## 🎯 它是做什么的？

OpenCut 是一个开源的视频编辑器，可以让你在浏览器、电脑或手机上免费剪辑视频。它是 CapCut（剪映国际版）的开源替代品，完全免费且代码公开。

**核心特点：**
- **跨平台**：一套代码支持 Web、桌面和移动端
- **完全免费**：MIT 开源协议，无需付费
- **插件架构**：即将支持第三方插件扩展功能
- **AI 友好**：将提供 MCP 服务器供 AI 智能体调用
- **可编程**：内置脚本编辑器，支持自动化批量渲染

**当前状态：**
项目正在从零重写中，旧版本仍在 [opencut.app](https://opencut.app) 运行，新版本将在 [new.opencut.app](https://new.opencut.app) 测试。

## 🔑 核心概念解读

**开源视频编辑器**
- 专业说法：源代码公开、可自由修改和分发的视频编辑软件
- 通俗说：就像免费的自助餐厨房，你可以直接使用，也可以查看食谱（代码）自己改良

**CapCut 替代品**
- 专业说法：功能对标字节跳动旗下视频编辑 CapCut 的同类产品
- 通俗说：就像免费版 Photoshop vs GIMP，功能相似但一个收费一个免费

**编辑器 API**
- 专业说法：提供编程接口让其他软件调用视频编辑功能
- 通俗说：就像餐厅的外卖窗口，其他程序可以"点餐"让 OpenCut 处理视频

**MCP 服务器（Model Context Protocol）**
- 专业说法：支持 AI 智能体调用的协议接口
- 通俗说：给 AI 聊天机器人开的"后门"，让 AI 可以直接操作视频编辑

**无头模式（Headless）**
- 专业说法：无图形界面的后台运行模式
- 通俗说：就像后台自动渲染队列，不需要打开软件界面就能批量干活

## 💡 切实可落地的例子

### 场景 1：YouTuber 批量制作视频

**痛点**：每周要制作 5 个视频，手动重复剪辑太耗时

**解决方案**：使用 OpenCut 的无头模式批量渲染

**具体实现步骤**：
```bash
# 安装 OpenCut Desktop（即将发布）
# 编写脚本自动化编辑流程
# 批量渲染多个视频项目
opencut render --batch --input ./projects/*.opencut --output ./rendered/
```

**效果**：设置一次后，每周节省 3 小时手动操作时间

### 场景 2：开发者集成视频编辑到自己的应用

**痛点**：想在 App 里加视频编辑功能，但从零开发太复杂

**解决方案**：使用 OpenCut 的编辑器 API

**具体实现步骤**：
```javascript
// 在你的 Web 应用中嵌入 OpenCut 编辑器
import { OpenCutEditor } from '@opencut/editor';

const editor = new OpenCutEditor({
  container: '#video-editor',
  projectId: 'my-project-123',
  onExport: (videoBlob) => {
    // 处理导出的视频
    uploadToServer(videoBlob);
  }
});

// 开启编辑器
editor.open();
```

**效果**：无需从零开发，快速为应用添加专业视频编辑功能

### 场景 3：AI 智能体自动化视频剪辑

**痛点**：想用 AI 自动生成视频，但缺少可编程的编辑器

**解决方案**：通过 MCP 服务器让 AI 直接操作 OpenCut

**具体实现步骤**：
```python
# AI 智能体调用 OpenCut MCP 服务
import anthropic
from mcp import Client

# 连接到 OpenCut MCP 服务器
mcp_client = Client('localhost:3000')

# AI 分析内容并生成编辑指令
client = anthropic.Anthropic()
response = client.messages.create(
    model="claude-sonnet-4-6",
    tools=[mcp_client.get_tools()],
    messages=[{
        "role": "user",
        "content": "把这个 10 分钟的视频剪成 3 个高光片段"
    }]
)

# OpenCut 自动执行剪辑操作
```

**效果**：AI 可以直接操作视频编辑器，实现真正的自动化剪辑工作流
