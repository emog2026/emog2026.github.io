## 🎯 它是做什么的？

Obscura 是一个**超轻量级、超快速的无头浏览器引擎**，用 Rust 编写，专为网页抓取和 AI 智能体自动化设计。

想象一下：
- 你需要抓取 1000 个网页的数据，Chrome 无头模式会吃掉 20GB 内存
- 你想批量爬取数据，但网站会检测并封禁自动化工具
- 你的 AI 智能体需要快速访问网页，但启动 Chrome 太慢了

Obscura 就是专门解决这些问题的——它像是一个"特种兵版"的 Chrome：
- **只有 30MB 内存**（Chrome 要 200MB+）
- **瞬间启动**（Chrome 要等 2 秒）
- **内置反检测功能**（网站看不出你是机器人）
- **完全兼容 Puppeteer 和 Playwright**（不用重写代码）

**对比 Headless Chrome：**
| 指标 | Obscura | Headless Chrome |
|------|---------|-----------------|
| 内存占用 | 30 MB | 200+ MB |
| 二进制大小 | 70 MB | 300+ MB |
| 启动时间 | 瞬间 | ~2 秒 |
| 页面加载 | 85 ms | ~500 ms |
| 反检测功能 | ✅ 内置 | ❌ 无 |

## 🔑 核心概念解读

### 1️⃣ **Headless Browser（无头浏览器）**
- **专业说**：没有图形界面的浏览器引擎
- **通俗说**：就像"隐形版" Chrome——能跑网页、执行 JavaScript，但你看不到窗口
- **生活中的类比**：就像后台运行的下载器，不用打开软件界面也能干活

### 2️⃣ **Web Scraping（网页抓取）**
- **专业说**：自动从网站提取数据的技术
- **通俗说**：让程序自动"读网页"并保存有用信息
- **生活中的类比**：雇佣 100 个速记员同时抄写 100 个网页的内容

### 3️⃣ **Anti-Detection（反检测）**
- **专业说**：绕过网站机器人检测的技术
- **通俗说**：让自动化工具伪装成真人操作
- **生活中的类比**：就像间谍潜入敌营，伪装成当地人不被发现

### 4️⃣ **CDP（Chrome DevTools Protocol）**
- **专业说**：控制浏览器的标准化协议
- **通俗说**：用代码"遥控"浏览器的通用语言
- **生活中的类比**：像电视遥控器和电视之间的通讯协议

## 💡 切实可落地的例子

### **场景 1：电商价格监控（个人副业）**
- **痛点**：想在淘宝、京东监控 1000 个商品价格，用 Chrome 开 50 个实例就爆内存了
- **方案**：Obscura 并发运行 50 个实例，内存只占 1.5GB（Chrome 要 10GB+）
- **效果**：轻松监控 1000+ 商品，电脑不卡顿，数据实时更新

### **场景 2：AI 智能体开发（创业公司）**
- **痛点**：你的 AI 助手需要访问网页回答问题，但每次启动 Chrome 要等 2 秒，用户体验很差
- **方案**：用 Obscura 替换，瞬间启动，响应速度提升 10 倍
- **效果**：AI 回答从"5 秒"变成"0.5 秒"，用户满意度飙升

### **场景 3：大规模数据采集（企业级）**
- **痛点**：爬取新闻网站数据，对方有 Cloudflare 防护，普通工具一连接就被封
- **方案**：启用 Obscura 的 stealth 模式（反检测），伪装成真实浏览器
- **效果**：成功绕过检测，数据采集成功率从 20% 提升到 98%

## 🚀 快速开始

### 安装

```bash
# Linux x86_64
curl -LO https://github.com/h4ckf0r0day/obscura/releases/latest/download/obscura-x86_64-linux.tar.gz
tar xzf obscura-x86_64-linux.tar.gz
./obscura fetch https://example.com --eval "document.title"

# macOS Apple Silicon
curl -LO https://github.com/h4ckf0r0day/obscura/releases/latest/download/obscura-aarch64-macos.tar.gz
tar xzf obscura-aarch64-macos.tar.gz
```

### 基本使用

```bash
# 获取网页标题
obscura fetch https://example.com --eval "document.title"

# 提取所有链接
obscura fetch https://example.com --dump links

# 渲染 JavaScript 并输出 HTML
obscura fetch https://news.ycombinator.com --dump html

# 启动 CDP 服务器（兼容 Puppeteer/Playwright）
obscura serve --port 9222

# 并发抓取多个网页
obscura scrape url1 url2 url3 ... \
  --concurrency 25 \
  --eval "document.querySelector('h1').textContent" \
  --format json
```

### Puppeteer 集成

```javascript
import puppeteer from 'puppeteer-core';

const browser = await puppeteer.connect({
  browserWSEndpoint: 'ws://127.0.0.1:9222/devtools/browser',
});

const page = await browser.newPage();
await page.goto('https://news.ycombinator.com');

const stories = await page.evaluate(() =>
  Array.from(document.querySelectorAll('.titleline > a'))
    .map(a => ({ title: a.textContent, url: a.href }))
);
console.log(stories);

await browser.disconnect();
```
