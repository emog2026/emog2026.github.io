📌 **一句话总结**: 自动收集整理全网免费电视直播源,直接复制链接就能看

🎯 **它是做什么的?**

CCSH/IPTV 是一个"直播源自动化搬运工",帮你:

- 自动从互联网收集免费的电视直播源(央视、卫视、地方台等)
- 整理成标准格式(TXT/M3U),复制链接就能用
- 自动更新台标 Logo 和电子节目单(EPG)
- 兼容电视盒子、手机 APP、电脑播放器
- GitHub Actions 全自动运维,每天更新,无需手动维护

就像一个"免费的电子节目单+直播源管理器",不用你自己去找直播源链接。

🔑 **核心概念解读**

**直播源**

- 专业说:IPTV 直播流的 URL 地址列表
- 通俗说:电视频道的"网络地址",就像每个电视台有一个"电话号码",播放器拨打这个号码就能看直播

**EPG 电子节目指南**

- 专业说:Electronic Program Guide,包含节目预告信息的 XML 数据
- 通俗说:电视节目单,告诉你现在在播什么、接下来播什么、节目简介

**M3U 格式**

- 专业说:多媒体播放列表格式标准
- 通俗说:播放器能识别的"频道列表文件",就像一个"播放清单"

**GitHub Actions**

- 专业说:GitHub 提供的 CI/CD 自动化工作流
- 通俗说:GitHub 上的"定时机器人",每天按时帮你干活(采集、更新、发布)

💡 **切实可落地的例子**

**场景 1:家里电视看免费频道**

- 痛点:电视盒子看央视、卫视要装好多 APP,还有广告
- 解决方案:用 CCSH/IPTV 的直播源,直接在电视盒子播放器里添加
- 具体步骤:
  ```bash
  # 1. 获取直播源链接(选择其中一个)
  完整版(含地方台):
  https://raw.githubusercontent.com/CCSH/IPTV/refs/heads/main/live.m3u

  精简版(不含地方台):
  https://raw.githubusercontent.com/CCSH/IPTV/refs/heads/main/live_lite.m3u

  # 2. 获取节目单链接
  https://raw.githubusercontent.com/CCSH/IPTV/refs/heads/main/e.xml

  # 3. 电视盒子操作流程(TiviMate 为例)
  # 打开 TiviMate → 添加频道列表 → 粘贴 live.m3u 链接
  # 设置 → EPG → 粘贴 e.xml 链接
  # 完成!现在可以看到央视、卫视、地方台等频道
  ```
- 效果:免费看 100+ 频道,自动更新节目单,无广告

**场景 2:手机用直播 APP 看电视**

- 痛点:手机看电视要下载官方 APP,限地区、有广告、不更新
- 解决方案:用手机 IPTV APP(如 TVerial、IPTV Core)加载 CCSH/IPTV 直播源
- 具体步骤:
  ```bash
  # Android 手机操作流程:
  # 1. 安装 IPTV 播放器 APP(推荐 TVerial)
  # 2. 打开 APP → 添加播放列表 → 选择 "从 URL 添加"
  # 3. 粘贴直播源链接:
  https://raw.githubusercontent.com/CCSH/IPTV/refs/heads/main/live.m3u
  # 4. 添加 EPG 链接:
  https://raw.githubusercontent.com/CCSH/IPTV/refs/heads/main/e.xml
  # 5. 扫描频道 → 完成
  ```
- 效果:手机免费看央视、卫视、地方台,随时看节目单

**场景 3:自建 IPTV 服务(给家人朋友用)**

- 痛点:家人朋友都要看电视,每人都要配置一遍太麻烦
- 解决方案:Fork 仓库自用,生成自己的直播源链接分享给家人
- 具体步骤:
  ```bash
  # 1. Fork 仓库到自己的 GitHub
  # 访问 https://github.com/CCSH/IPTV
  # 点击右上角 Fork 按钮

  # 2. 启用 GitHub Actions
  # 进入你 Fork 的仓库 → Actions 标签页
  # 点击 "I understand my workflows, go ahead and enable them"

  # 3. 获取自己的直播源链接
  # 将原始链接中的 CCSH/IPTV 替换为 你的用户名/IPTV
  # 例如:https://raw.githubusercontent.com/张三/IPTV/refs/heads/main/live.m3u

  # 4. 分享给家人朋友
  # 把你的链接发给家人,他们直接复制就能用
  ```
- 效果:一家人用你维护的直播源,每天自动更新,稳定可靠
