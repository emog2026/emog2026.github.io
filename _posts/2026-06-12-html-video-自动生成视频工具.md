## 📌 一句话总结

让AI自动把文章、代码或网页变成精美视频的工具

---

## 🎯 它是做什么的？

html-video是一个"视频自动化工厂"。想象一下：

- 你扔给AI一篇微信公众号文章 → 它自动生成多场景解读视频
- 你给个GitHub仓库链接 → 它自动做成项目介绍视频  
- 你描述一个产品 → AI自动写文案、选模板、渲染成MP4

全程在**你的电脑本地完成**，不用上传到云端，没有渲染次数限制，永久免费使用（Apache-2.0开源协议）。

---

## 🔑 核心概念解读

### Agent（AI助手）

- **专业说**：支持的14种编码AI助手，包括Claude Code、Cursor、Copilot等
- **通俗说**：你的"视频导演团队"——它们负责读内容、写文案、选风格

### Template（视频模板）

- **专业说**：21种精心策划的单文件HTML动画模板
- **通俗说**：像PPT主题，但是会动的——数据图表、故障风标题、电影感转场等

### Content Graph（内容图谱）

- **专业说**：多帧视频的故事板中间表示
- **通俗说**：AI写好的"分镜头脚本"——这一帧讲什么，下一帧接什么

## 💡 切实可落地的例子

### 场景1：技术博主

**痛点**：写好技术文章，想做视频版但要手动剪辑、录屏、配音

**解决方案**：扔给AI你的文章链接 → 自动生成带数据图表、代码演示的讲解视频

**具体实现步骤**：
```bash
# 安装依赖
pnpm install
pnpm -r build
node packages/cli/dist/bin.js studio

# 在浏览器中打开 http://127.0.0.1:3071
# 粘贴文章链接，选择"NYT数据图表"模板，点击生成
```

**实际效果**：一篇1500字文章 → 3分钟专业讲解视频，从几小时人工剪辑变成5分钟AI生成

---

### 场景2：开源项目维护者

**痛点**：GitHub项目想做宣传视频，但不会视频剪辑

**解决方案**：粘贴GitHub仓库链接 → AI自动读取README、生成项目介绍视频

**具体实现步骤**：
```bash
# 在studio中点击"从链接生成"
# 输入: https://github.com/your-username/your-project
# 选择"产品推广"模板，让AI自动提取项目亮点
```

**实际效果**：自动生成15-30秒项目介绍视频，直接用于README或社交媒体

---

### 场景3：内容创作者

**痛点**：需要大量短视频，但每个都要从头制作

**解决方案**：批量生成文章视频 → 加上AI配音和背景音乐

**具体实现步骤**：
```bash
# 配置MiniMax API key（用于AI配音和音乐）
# 在Settings → Audio中添加密钥
# 在Soundtrack面板选择背景音乐情绪："calm cinematic ambient"
# 输入配音脚本，AI自动混音到视频中
```

**实际效果**：一条文章 → 一个完整带配音的短视频，节省数小时制作时间

## ⚠️ 注意事项

- **完全免费**（Apache-2.0开源协议），无渲染次数限制
- **本地渲染**：需要较好的电脑配置（推荐8GB+内存）
- **学习曲线**：⭐⭐⭐☆☆（需要Node.js基础，但官方有详细文档）
- **替代方案**：Remotion（React视频框架）、Motion Canvas（代码驱动动画）
- **前置要求**：
  - Node.js 20+
  - pnpm 9+
  - ffmpeg
  - Chromium（或Playwright浏览器）

**项目特点**：

- **14种编码Agent支持**：Open Design、Claude Code、Cursor、Copilot等
- **21种精心策划的模板**：数据图表、产品推广、故障风标题、电影感转场等

- **AI音轨**：可选的背景音乐和旁白，通过MiniMax API生成
