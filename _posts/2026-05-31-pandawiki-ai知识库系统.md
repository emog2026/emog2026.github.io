## 📌 一句话总结

AI 驱动的开源 Wiki 系统，让文档自动写、自动答、自动搜

---

## 🎯 它是做什么的？

PandaWiki 是长亭科技（chaitin）开源的 **AI 知识库搭建系统**，帮你快速构建智能化的产品文档、技术文档、FAQ、博客系统。

**核心能力：**
- 🤖 **AI 创作** — 让 AI 帮你写文档、生成内容
- 💬 **AI 问答** — 上传文档，AI 自动回答问题（基于你的知识库）
- 🔍 **AI 搜索** — 语义搜索，不是傻傻的关键词匹配

**关键特性：**
- 📝 兼容 Markdown/HTML，可导出 Word/PDF
- 🔌 支持嵌入第三方网站（网页挂件）
- 💬 集成钉钉、飞书、企业微信机器人
- 📥 支持从网页 URL、Sitemap、RSS、文件批量导入

---

## 🔑 核心概念解读

| 专业术语 | 通俗解释 |
|---------|---------|
| **AI 知识库** | 不光是存文档，AI 会"读懂"你的文档，然后帮别人回答问题 |
| **向量检索** | 让 AI 理解"意思相近"，搜"怎么退款"能找到"退货流程" |
| **知识库分库** | 像图书馆一样，产品文档、技术文档、FAQ 分开管理，各自独立 |
| **AI 创作** | 给 AI 一个主题，它自动生成文档初稿，你只需修改润色 |
| **网页挂件** | 把 Wiki 嵌入你的官网，用户不跳转就能搜索文档 |

## 💡 切实可落地的例子

### 场景 1：SaaS 产品团队 — 自动化产品文档

**痛点**：产品更新快，文档跟不上，客服天天回答重复问题

**解决方案**：用 PandaWiki 搭建产品文档系统

**具体步骤**：
```bash
# 1. 安装 PandaWiki（需要 Linux 服务器 + Docker 20.x+）
bash -c "$(curl -fsSLk https://release.baizhi.cloud/panda-wiki/manager.sh)"

# 安装完成后会显示访问信息：
# SUCCESS  访问地址: http://your-server-ip:2443
# SUCCESS  用户名: admin
# SUCCESS  密码: **************

# 2. 浏览器打开控制台，首次登录配置 AI 模型
# 推荐使用"一键配置"，选择百智云模型广场
# 注册即可获赠 5 元额度，足够测试

# 3. 创建知识库
# 控制台 → 创建知识库 → 填写名称"产品文档"
# 上传你的产品手册 PDF/Word 文档

# 4. 等待 AI 学习完成（几分钟）

# 5. 测试 AI 问答
# 访问 Wiki 网站前台 → 搜索框输入"如何退款"
# AI 基于你的文档给出准确答案
```

**效果**：
- 客服问题减少 60%
- 新员工上手时间从 3 天降到 2 小时
- 产品更新后，用 AI 创作功能快速生成文档初稿

### 场景 2：技术团队 — 内部知识库 + AI 助手

**痛点**：技术散落在各处，新人问来问去，老人被打断

**解决方案**：搭建技术知识库 + 钉钉/飞书机器人

**具体步骤**：
```bash
# 1. 创建技术文档知识库
# 登录 PandaWiki 控制台 → 创建知识库 → "技术文档"

# 2. 批量导入现有文档
# 方式 A：从网页 URL 导入（如果有 Confluence/Notion）
# 控制台 → 导入内容 → 网页 URL → 输入链接列表

# 方式 B：从 Sitemap 导入（批量抓取整个文档站）
# 控制台 → 导入内容 → Sitemap → 输入 https://docs.yourcompany.com/sitemap.xml

# 方式 C：上传本地文件
# 控制台 → 上传文档 → 选择所有 .md/.pdf/.docx 文件

# 3. 配置钉钉/飞书机器人
# 控制台 → 集成配置 → 选择"钉钉"
# 按照 Webhook 配置指南，将 PandaWiki 接入钉钉群

# 4. 在钉钉群测试
# @机器人 "怎么部署项目？"
# 机器人基于技术文档给出准确答案
```

**效果**：
- 新人问题自己解决，不再打扰老人
- 文档更新后，机器人自动同步
- 搜索"怎么连数据库"，能找到"数据库配置指南"

### 场景 3：创业公司 — 快速搭建 FAQ + 客服机器人

**痛点**：客服成本高，但又不想用外包客服

**解决方案**：PandaWiki + 企业微信机器人

**具体步骤**：
```bash
# 1. 创建 FAQ 知识库
# 控制台 → 创建知识库 → "客户 FAQ"

# 2. 用 AI 创作功能生成 FAQ 初稿
# 控制台 → AI 创作 → 输入主题"电商退换货政策"
# AI 自动生成 FAQ 文档，你只需审核修改

# 3. 从邮箱导出客户常见问题
# 导出邮件 → 整理成 Excel → 转成 CSV
# 控制台 → 上传文档 → 选择 CSV

# 4. 配置企业微信机器人
# 控制台 → 集成配置 → 选择"企业微信"
# 配置 Webhook 和关键词触发

# 5. 嵌入官网
# 控制台 → 网站挂件 → 复制嵌入代码
# 粘贴到你的官网 <body> 中
```

**效果**：
- 官网右下角出现智能搜索框
- 客户自己找答案，客服工作量减半
- 企业微信机器人 24/7 响应客户问题

### 场景 5：企业级部署 — 多知识库管理

**痛点**：部门多，文档分散，没法统一管理

**解决方案**：创建多个知识库，各自独立管理

**具体步骤**：
```bash
# 1. 为不同部门创建独立知识库
# 控制台 → 创建知识库 → "产品文档"（产品部用）
# 控制台 → 创建知识库 → "技术文档"（技术部用）
# 控制台 → 创建知识库 → "销售话术"（销售部用）
# 控制台 → 创建知识库 → "HR 制度"（人事部用）

# 2. 配置权限管理
# 控制台 → 用户管理 → 创建用户 → 分配知识库权限
# 产品经理只能编辑"产品文档"
# 技术人员只能编辑"技术文档"

# 3. 各部门独立集成
# 产品部：嵌入官网帮助中心
# 技术部：集成钉钉机器人
# 销售部：集成企业微信
# 人事部：内部 Wiki 访问

# 4. 统一管理后台
# 控制台 → 知识库管理 → 查看所有知识库的统计
# （文档数量、AI 问答次数、搜索热词）
```

**效果**：
- 各部门文档独立，不混乱
- 统一的管理后台，方便维护
- 每个知识库可以有独立的 AI 模型配置

### 场景 6：从现有文档系统迁移

**痛点**：文档在 Confluence/Notion/语雀，想迁移到自己的系统

**解决方案**：用 PandaWiki 的批量导入功能

**具体步骤**：
```bash
# 方式 A：从网页 URL 导入（适合公开文档）
# 1. 先把 Confluence 页面导出为公开 URL
# 2. 整理所有 URL 成一个列表（urls.txt）
# 3. 控制台 → 导入内容 → 网页 URL → 批量导入
# 4. 粘贴 URL 列表，点击导入

# 方式 B：从 Sitemap 导入（适合整个站点）
# 控制台 → 导入内容 → Sitemap
# 输入：https://docs.yourcompany.com/sitemap.xml
# PandaWiki 自动抓取所有页面

# 方式 C：从 RSS 订阅导入（适合博客/新闻）
# 控制台 → 导入内容 → RSS 订阅
# 输入 RSS 链接，自动同步更新内容

# 方式 D：上传本地文件
# 1. 从 Confluence/Notion 导出为 PDF/Word
# 2. 控制台 → 上传文档 → 批量上传
# 3. 等待 AI 学习完成
```

**效果**：
- 一次性迁移数百篇文档
- AI 自动学习，迁移完就能用
- 支持 PDF、Word、Markdown、HTML 等多种格式
