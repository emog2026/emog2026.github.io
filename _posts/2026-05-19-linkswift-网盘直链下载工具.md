## 🎯 它是做什么的？

LinkSwift 是一个"网盘下载加速器"。想象一下：

- 你想从百度网盘下载大文件，但官方客户端限速慢如蜗牛
- 分享的文件希望用 IDM、迅雷等专业下载器管理，但网盘不提供直链
- 同时使用多个网盘服务，每个都要安装独立客户端太占空间

**LinkSwift 的解决方案：**
- 直接在浏览器中获取网盘文件的直链下载地址
- 无需安装官方客户端，一个脚本搞定八大网盘
- 支持推送到 IDM、Aria2、Motrix 等专业下载工具
- 额外提供界面美化、广告移除等增强功能

**支持网盘：** 百度网盘、阿里云盘、中国移动云盘、天翼云盘、迅雷云盘、夸克网盘、UC网盘、123云盘

## 🔑 核心概念解读

### 用户脚本
- **专业说**：通过浏览器扩展（如 Tampermonkey）注入到网页的 JavaScript 代码
- **通俗说**：给浏览器装个"插件"，让网盘网页按你的意愿工作

### 直链下载
- **专业说**：直接访问文件资源的 URL，绕过官方客户端的中转层
- **通俗说**：就像从快递员手里直接拿包裹，不用去网点排队

### RPC 推送
- **专业说**：通过远程过程调用协议将下载任务发送到下载器
- **通俗说**：告诉你的下载工具"开始下载这个"，就像点一下鼠标一样简单

### API 下载
- **专业说**：通过网盘公开的编程接口获取文件元数据和下载地址
- **通俗说**：用网盘官方提供的"后门"通道获取文件，安全稳定

## 💡 切实可落地的例子

### 场景 1：大学生下载学习资料

- **痛点**：课程资料在百度网盘，非会员限速 100KB/s，1GB 文件要下 3 小时
- **解决方案**：使用 LinkSwift 获取直链，用 IDM 或浏览器直接下载
- **具体步骤**：
  1. 安装 Tampermonkey 浏览器扩展
  2. 访问 https://github.com/hmjz100/LinkSwift 点击"正式版"安装脚本
  3. 打开百度网盘分享链接，勾选文件
  4. 点击新增的"API 下载"按钮
  5. 选择"复制链接"或"推送到 IDM"
- **效果**：下载速度提升 5-10 倍（取决于网络环境）

### 场景 2：自媒体人批量下载素材

- **痛点**：客户通过不同网盘分享素材，每天要处理 10+ 个下载任务
- **解决方案**：用 LinkSwift + Aria2 实现批量下载自动化
- **具体步骤**：
  1. 在本地搭建 Aria2 下载服务（Docker 一键部署）
  2. LinkSwift 设置中配置 Aria2 RPC 地址
  3. 遇到网盘链接时，点击"推送到 Aria2"
  4. 所有下载任务统一管理，支持断点续传
- **效果**：每天节省 1 小时下载操作时间，所有素材集中管理

### 场景 3：企业文件备份与迁移

- **痛点**：需要定期从客户的多个网盘账户备份文件到企业存储
- **解决方案**：LinkSwift 获取直链 + rclone 云端同步
- **具体步骤**：
  ```bash
  # 1. 用 LinkSwift 获取文件直链
  # 2. 使用 rclone 直接同步
  rclone copy "http://直链地址" "企业网盘:/备份/2026-05-19/" \
    --progress --stats 1s
  
  # 3. 配合 cron 定时任务自动化
  ```
- **效果**：无需登录客户账号，安全高效完成批量备份
