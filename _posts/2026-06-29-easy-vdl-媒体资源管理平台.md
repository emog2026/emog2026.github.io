## 🎯 它是做什么的？

**Easy-VDL**（综合媒体资源管理平台）是一款集**视频订阅、直播录制、智能剪辑、GPU 硬件加速转码**与媒体服务器联动的可视化内容管理平台。

想象一下：
- 你关注了 10 个博主，每次手动下载新视频太麻烦
- 想录制喜欢的直播间，但不想一直守着电脑
- 3 小时的直播，只想看精彩片段
- 下载的视频想用 Emby/Jellyfin 管理，但元数据太乱
- NAS 上的视频播放卡顿，没有硬件加速

**Easy-VDL 解决这些问题：**
- 🎬 **多平台订阅**：抖音、快手、YouTube、B站、小红书、TikTok、Instagram、X 自动检测更新
- 🔴 **直播自动录制**：开播自动录，停播自动转码，无缝时间轴回放
- 📜 **弹幕同步回放**：录制弹幕，回放时同步浏览历史弹幕
- 🤖 **AI 智能切片**：基于弹幕热度自动提取精彩片段，DeepSeek 生成标题摘要
- 🔔 **智能通知**：微信、Telegram、Server酱、Bark 全平台推送
- ✈️ **Telegram 直传**：支持 2GB 大文件直传至 Bot 并自动转存
- 🍿 **Emby/Jellyfin 联动**：自动生成 NFO 元数据与精美海报墙
- ⚡ **硬件加速**：Intel/AMD 核显（QSV/VAAPI）与 NVIDIA 显卡硬件加速转码

**核心特点：Docker 一键部署，支持 x86_64 与 ARM64（含 Apple Silicon）**

## 🔑 核心概念解读

**多平台视频订阅（Multi-platform Video Subscription）**
- **专业说**：通过 RSS/API 接口自动检测目标平台内容更新并归档
- **通俗说**：像关注博主，一有新内容自动下载，不用手动检查

**弹幕同步回放（Danmaku Sync Replay）**
- **专业说**：录制过程中同步记录弹幕时间流，回放时 WebSocket 实时推送
- **通俗说**：像看回放也能看到当时的弹幕，还原现场氛围

**AI 智能切片（AI Highlight Extraction）**
- **专业说**：基于弹幕热度与情感分析自动提取精彩片段，LLM 生成标题摘要
- **通俗说**：AI 自动剪辑最精彩的部分，还自动起标题写简介

**硬件加速转码（Hardware Acceleration）**
- **专业说**：利用 GPU（QSV/VAAPI/CUDA）进行视频解码与转码，降低 CPU 负载
- **通俗说**：用显卡处理视频，省 CPU，播放更流畅

**NFO 元数据（NFO Metadata）**
- **专业说**：符合 Emby/Jellyfin 标准的 XML 格式元数据文件
- **通俗说**：给视频附带"身份证"，包含标题、演员、海报等信息

**Telegram 直传（Telegram Direct Transfer）**
- **专业说**：基于 MTProto 协议直接向 Bot 传输大文件
- **通俗说**：从 Telegram 直接拖文件到本地，不需要中转

## 💡 切实可落地的例子（3个场景）

### **场景 1：UP 主视频自动归档**
- **痛点**：关注的 20 个 UP 主，每天手动检查太累
- **解决方案**：用 Easy-VDL 订阅功能，自动检测并下载
- **具体实现步骤**：
  ```bash
  # 1. 创建 docker-compose.yml
  version: '3.8'
  services:
    easy-vdl:
      image: qq918652593/easy-vdl:latest
      container_name: easy-vdl
      ports:
        - "888:80"
      mem_limit: 4g
      devices:
        - /dev/dri:/dev/dri  # Intel/AMD 核显加速
      volumes:
        - ./downloads:/app/downloads
        - ./logs:/app/logs
        - ./database:/app/database
      environment:
        - EASY_VDL_PORT=80
        - PUID=1000
        - PGID=100
        - TZ=Asia/Shanghai
      restart: unless-stopped

  # 2. 启动服务
  docker-compose up -d

  # 3. 浏览器访问 http://localhost:888
  # 登录（默认 admin/admin123456）

  # 4. 订阅页面 → 添加 B站 UP 主主页链接
  # 设置检测间隔：每小时检查一次

  # 5. 系统自动下载新视频到 ./downloads
  ```
- **效果**：UP 主一更新视频，系统自动下载，无需手动干预

### **场景 2：精彩直播自动剪辑**
- **痛点**：3 小时游戏直播，只想看精彩击杀时刻
- **解决方案**：直播录制 + AI 智能切片
- **具体实现步骤**：
  ```bash
  # 1. 启动 Easy-VDL（如场景 1）

  # 2. 直播页面 → 添加直播间地址（抖音/B站/虎牙）
  # 系统自动检测直播状态

  # 3. 开播时自动录制，停播后自动转码

  # 4. AI 智能切片自动分析弹幕热度
  # 提取精彩片段 → DeepSeek 生成标题和摘要

  # 5. 一键导出剪辑素材到 ./downloads/highlights
  ```
- **效果**：3 小时直播 → 5 分钟精彩集锦，AI 自动剪辑

### **场景 3：NAS 家庭媒体中心**
- **痛点**：NAS 视频多，Emby 播放卡，元数据混乱
- **解决方案**：Easy-VDL + Emby/Jellyfin 完美联动
- **具体实现步骤**：
  ```bash
  # 1. 群晖/威联通 NAS 上部署 Easy-VDL
  # ARM64 版本：qq918652593/easy-vdl:arm64

  # 2. 挂载 NAS 共享文件夹
  volumes:
    - /volume1/video:/app/downloads  # 机械硬盘存视频
    - /volume1/database:/app/database  # SSD 存数据库

  # 3. 订阅 UP 主/博主 → 视频自动下载到 NAS

  # 4. Easy-VDL 自动生成 NFO 元数据和海报
  # Emby/Jellyfin 自动识别，完美展示

  # 5. 内置播放器硬件加速（QSV/VAAPI）
  # NAS 核显转码，流畅播放 4K
  ```
- **效果**：NAS 变身专业媒体中心，硬件加速播放，元数据完美

## 🚀 极速部署

### Docker Compose（推荐）

```yaml
version: '3.8'
services:
  easy-vdl:
    image: qq918652593/easy-vdl:latest
    container_name: easy-vdl
    ports:
      - "888:80"
    mem_limit: 4g
    devices:
      - /dev/dri:/dev/dri  # Intel/AMD 核显
    volumes:
      - ./downloads:/app/downloads
      - ./logs:/app/logs
      - ./database:/app/database
    environment:
      - EASY_VDL_PORT=80
      - PUID=1000
      - PGID=100
      - TZ=Asia/Shanghai
    restart: unless-stopped
```

### 运行命令

```bash
# 启动
docker-compose up -d

# 访问 http://localhost:888
# 默认账号：admin
# 默认密码：admin123456
```

## 🎛️ 环境变量说明

| 变量名 | 说明 | 默认值 | 推荐 |
|--------|------|--------|------|
| `EASY_VDL_PORT` | 容器内部端口 | `80` | 保持 80 |
| `PUID` / `PGID` | 用户 UID/GID | `1000`/`100` | 匹配宿主机 |
| `EASY_VDL_ADMIN_USERNAME` | 管理员账号 | `admin` | 必选 |
| `EASY_VDL_ADMIN_PASSWORD` | 管理员密码 | `admin123456` | 建议修改 |
| `SNIFFER_LICENSE_KEY` | 高级功能授权 | 无 | 可选 |
| `TZ` | 时区 | `Asia/Shanghai` | 推荐 |
