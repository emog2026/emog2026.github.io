## 📌 一句话总结
全自动 AI 短视频生成引擎：输入主题，自动写稿、配音、配图、合成视频

---

## 🎯 它是做什么的？

Pixelle-Video 是一个"AI 视频制作工厂"。想象一下：
- 输入主题"为什么要养成阅读习惯" → AI 自动写文案、生成配图、合成语音 → 输出完整短视频
- 不懂剪辑、不会配音、没学过设计也能做视频
- 全程在 Web 界面点击操作，无需写代码

**解决的核心问题**：把传统需要文案+配音+剪辑+设计团队的短视频制作流程，变成一个人 5 分钟搞定。

---

## 🔑 核心概念解读

**1. TTS 工作流（语音合成）**
- 专业说：文本转语音技术，将文字生成音频
- 通俗说：像"给文字装上嘴巴"，AI 把稿子读出来
- 支持声音克隆：上传参考音频，AI 能模仿那个声音

**2. ComfyUI 工作流（图像生成）**
- 专业说：基于 Stable Diffusion 的节点化图像生成流程
- 通俗说：像搭积木一样组合 AI 绘画模块，自动生成视频配图
- 可以自定义风格：动漫、写实、插画等

**3. 视频模板（布局系统）**
- 专业说：预设的 HTML/CSS 视频渲染模板
- 通俗说：像 PPT 模板，决定视频长什么样、文字放哪里、图片怎么排
- 三类模板：静态（文字）、图片（AI 配图）、视频（动态背景）

## 💡 切实可落地的例子

### **场景 1：自媒体博主批量产出知识内容**
- 痛点：每天要发视频，手动写稿+剪辑太累
- 方案：用 Pixelle-Video 主题生成模式
- **具体步骤**：
  ```bash
  # 1. 下载 Windows 一键包并解压
  # 2. 双击运行 start.bat
  # 3. 浏览器打开 http://localhost:8501
  # 4. 配置通义千问 API（成本极低）
  # 5. 输入主题："5个时间管理技巧"
  # 6. 选择 TTS 语音 + 内置 BGM
  # 7. 点击"生成视频"
  ```
- 效果：10 分钟产出 3 个视频，传统方式需要半天

### **场景 2：企业培训课程制作**
- 痛点：培训师要录 100 个课程视频，时间不够
- 方案：固定文案模式 + 批量生成
- **具体步骤**：
  ```bash
  # 1. 准备好 100 个培训课件文案（Word/PDF）
  # 2. 启动 Pixelle-Video Web 界面
  # 3. 选择"固定文案内容"模式
  # 4. 粘贴第一个课件文案
  # 5. 选择企业培训专用模板（templates/image_business.html）
  # 6. 使用参考音频（培训师真实声音）进行声音克隆
  # 7. 批量生成，每个视频 3 分钟完成
  ```
- 效果：1 人 1 周完成原需团队 1 月的工作量

### **场景 3：教育机构制作科普视频**
- 痛点：要给孩子做科普视频，但不会动画制作
- 方案：AI 自动配图 + 可爱语音
- **具体步骤**：
  ```bash
  # 1. 启动 Pixelle-Video
  # 2. 配置本地 ComfyUI（免费，需显卡）
  # 3. 输入主题："为什么天空是蓝色的"
  # 4. 提示词前缀填：Minimalist black-and-white matchstick figure style illustration, clean lines, simple sketch style
  # 5. 选择 Edge-TTS 儿童语音
  # 6. 选择 image_vertical.html 模板（竖屏适合手机观看）
  # 7. 生成后直接发抖音/视频号
  ```
- 效果：零设计基础也能做专业级科普视频

## ⚠️ 注意事项

**付费情况**：
- ✅ **完全免费方案**：本地 Ollama + 本地 ComfyUI = 0 元（需显卡）
- 💰 **推荐方案**：通义千问（LLM 成本极低）+ 本地 ComfyUI
- 💸💸 **云端方案**：OpenAI + RunningHub（费用高但无需本地环境）

**学习曲线**：⭐⭐☆☆☆（1-2 小时上手）

**系统要求**：
- Windows：一键包开箱即用
- macOS/Linux：需安装 uv 和 ffmpeg
- 本地 ComfyUI 需显卡（云端方案无要求）

**替代方案**：
- MoneyPrinterTurbo（类似视频生成工具）
- 剪映/必剪（手动剪辑，功能更强大）

---

## 📚 技术栈与架构

- **前端**：Streamlit Web UI（Python Web 框架）
- **AI 组件**：
  - LLM：支持通义千问、GPT-4o、DeepSeek、Ollama 本地模型
  - TTS：Edge-TTS、Index-TTS（支持声音克隆）
  - 图像生成：ComfyUI 工作流（本地/云端）
- **视频处理**：ffmpeg
- **包管理**：uv（Python 包管理器）
