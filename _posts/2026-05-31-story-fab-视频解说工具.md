📌 **一句话总结**: 本地 AI 自动把长视频切成爆款短视频 + 自动写解说稿配音

🎯 **它是做什么的?**

StoryFab 是一个"视频制作 AI 助手",能在你电脑上本地运行,帮你:

- 自动识别直播回放、游戏录像中的精彩片段并切分
- 给短剧/电影自动生成解说词
- 合成 AI 配音
- 导出 9:16(抖音竖屏)、1:1(小红书方屏)、16:9(横屏)等多种格式

所有 AI 处理都在本地完成,不用上传视频到云端,隐私安全。

🔑 **核心概念解读**

**剪辑模式 vs 解说模式**

- 专业说:两种不同的视频处理工作流
- 通俗说:
  - 剪辑模式 = 自动剪高光(像剪辑师自动挑精彩镜头)
  - 解说模式 = 自动做解说视频(像短视频博主那样讲故事)

**本地 Whisper 字幕**

- 专业说:基于 OpenAI Whisper 模型的本地语音识别
- 通俗说:不用联网,在你电脑上把视频语音转成文字字幕,速度快且隐私安全

**TTS 配音合成**

- 专业说:Text-to-Speech 文字转语音合成
- 通俗说:把解说词自动变成真人配音,不用自己录音

💡 **切实可落地的例子**

**场景 1:游戏主播剪辑个人素材**

- 痛点:3 小时直播录像,手动找精彩片段要花 2 小时
- 解决方案:用 StoryFab 剪辑模式自动识别五杀、精彩操作
- 具体步骤:
  ```bash
  # 安装依赖
  git clone https://github.com/Agions/story-fab.git
  cd story-fab
  npm install

  # 启动应用
  npm run tauri dev

  # 操作流程:
  # 1. 导入直播录像文件
  # 2. 选择"剪辑模式"
  # 3. AI 自动分析高光片段
  # 4. 选择 9:16 竖屏导出
  ```
- 效果:3 小时录像自动切成 10 个 30 秒高光短视频,直接发抖音/快手

**场景 2:短剧解说小团队**

- 痛点:一部 40 集短剧,手动写稿、配音、剪辑要 3 天
- 解决方案:用 StoryFab 解说模式全自动生成
- 具体步骤:
  ```bash
  # 导入短剧视频文件

  # 解说模式流程:
  # 1. AI 自动分段识别剧情节点
  # 2. "导演 Agent" 交互式策划解说风格
  # 3. 自动生成解说文案
  # 4. 本地 Edge TTS 合成配音

  ```
- 效果:40 集短剧自动生成 20 条 3 分钟解说视频,3 天工作量变 3 小时

- 痛点:每月要出 100 条解说视频,人工剪辑来不及
- 解决方案:批量处理电影片源,自动化生产流水线
- 具体步骤:
  ```bash

  for movie in movie_list/*.mp4; do
     # 1. 导入视频 → AI 分析剧情结构
  ```
