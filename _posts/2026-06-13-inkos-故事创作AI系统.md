📌 **一句话总结**：AI 驱动的长篇/短篇/互动小说创作工作台，从世界观设定到连载写作全流程自动化

🎯 **它是做什么的？**

InkOS 是一个**故事创作 AI Agent 系统**——想象你有个全能写作助手，能帮你：
- 建书时自动生成世界观、角色设定、卷纲
- 按章节持续写作、审稿、修订，保持长篇一致性
- 一键生成完整短篇（正文+简介+封面）
- 创建开放世界互动游戏（像文字冒险游戏）

它支持 Studio（Web 界面）、TUI（终端）、CLI 三种交互方式，底层共享同一套创作状态和记忆系统。

🔑 **核心概念解读**

**Agent（智能体）**
- 专业说：具有特定职责的 AI 模块（写手、审计员、规划师等）
- 通俗说：写作团队里的分工角色——有人专门写文，有人专门挑错，有人专门规划

**创作简报（Brief）**
- 专业说：作者输入的脑洞、设定文档，作为 AI 创作的基础
- 通俗说：你给写作团队的"需求文档"，告诉他们你想写什么、有什么设定

**记忆系统**
- 专业说：SQLite + 结构化 JSON + Markdown 投影三层记忆架构
- 通俗说：系统的"笔记本"，记录角色做了什么、物品在哪、伏笔是否回收，防止写崩

💡 **切实可落地的例子**

**场景 1：网文作者连载长篇小说**
- 痛点：每天更新，容易忘记之前的伏笔、角色性格、物品状态
- 方案：用 InkOS 建书，自动生成世界观和角色；每章自动审计连续性
- 具体实现：
```bash
# 安装
npm i -g @actalk/inkos

# 创建新书（修仙题材）
inkos book create --title "吞天魔帝" --genre xuanhuan

# 写下一章（草稿→审计→修订）
inkos write next 吞天魔帝

# 查看状态
inkos status 吞天魔帝

# 导出 EPUB
inkos export 吞天魔帝 --format epub
```
- 效果：系统自动记住角色、物品、伏笔，审计员检查每章是否矛盾

**场景 2：自媒体作者生成短篇内容**
- 痛点：需要批量生产短篇故事，手动写太慢
- 方案：用 InkOS Short 一键生成完整短篇包
- 具体实现：
```bash
# 通过 Studio 启动 Web 界面
inkos

# 在 Chat 里输入：
# "写一篇 12 章短篇，方向是：都市婚姻反转，女主拿到账本证据后反杀。"

# 或用 CLI：
inkos short run \
  --direction "都市短篇 婚姻反转 女主证据反杀" \
  --chapters 12 \
  --chars 1000
```
- 效果：生成 `full.md`（正文）、`sales-package.md`（简介卖点）、`cover-prompt.md`（封面提示词），配置封面服务后还能生成封面图

**场景 3：互动内容创作者做文字冒险游戏**
- 痛点：想做个文字游戏，但手动管理分支、状态太复杂
- 方案：用 InkOS Play 创建开放世界，让玩家自由探索
- 具体实现：
```bash
inkos
# 在 Studio 里选择「开放世界」

# 输入：
# "做一个魔兽风格的边境哨塔开放世界。
#  时间不是固定回合，巡逻是一小时，练功可以跨几天。
#  装备有稀有度，但不要数值面板，用材质和光泽体现。"
```
- 效果：系统维护世界状态（角色、物品、证据、关系、时间），支持自由动作输入和可点击选择，配置图片服务后自动生成场景/物品配图

## 技术亮点

### 多 Agent 协作架构
- **雷达**：扫描平台趋势和读者偏好
- **规划师**：读取作者意图生成本章意图
- **编排师**：按任务选择上下文，编译规则栈
- **写手**：基于精简上下文生成正文
- **观察者**：提取事实（角色、位置、资源、关系等）
- **审计员**：37 维度检查连续性和质量
- **修订者**：修复审计发现的问题

### 记忆与状态管理
- **三层记忆**：SQLite 时序数据库 + 结构化 JSON + Markdown 投影
- **伏笔系统**：Zod schema 校验，状态严格管理
- **上下文治理**：按 protected/compressible 分层组织，避免长书越写越乱

### 模型与配置
- **多模型路由**：不同 Agent 可用不同模型（写手用 Claude 审计用 GPT-4o）
- **国产模型支持**：月之暗面、MiniMax、智谱、百炼、DeepSeek 等
- **配置隔离**：Studio 用可视化配置，CLI 支持 env 覆盖

## 核心功能

### 长篇小说
从创作简报建书，生成世界观、角色、卷纲，按"写作 → 审稿 → 修订 → 状态结算"推进

### InkOS Short
直接产出独立短篇：正文、大纲、简介卖点、封面提示词，可生成封面图

### InkOS Play
开放世界与分支互动：支持世界契约、时间推进、角色 agent、物品/证据/关系状态、HUD 和自动配图

### 文风仿写
分析参考文本提取风格指纹，注入书籍让后续章节自动采用该风格

### 同人创作
支持正典延续、架空世界、性格重塑、CP 向四种模式

## 替代方案

- **通用 AI 写作工具**：Notion AI、Copy.ai（不支持长篇连续性）
- **网文助手**：各类网文 AI 助手（功能单一，缺乏完整工作流）
- **文字游戏引擎**：Twine、Ren'Py（需要手动编写所有内容）
