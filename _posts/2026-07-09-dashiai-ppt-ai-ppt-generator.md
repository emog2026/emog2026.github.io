---

🎯 **它是做什么的？**

dashiAI-ppt 是一个真正适合职场人的 AI PPT 生成技能。把任何文档丢给 AI Agent，几分钟后就能拿到：

- **可离线打开**的网页 PPT（HTML 格式）
- **可横向翻页**的完整演示体验
- **每一页都自带编辑控制台**——不满意直接在浏览器里改
- **一键导出成真实可编辑 PPTX**——不是"网页伪装的假 PPT"

核心特色：
- **12 套视觉主题**：轻拟态、炫光紫绿、深浅代码、玻璃糖果、色谱图表、深色图谱、冷白调研、黑金实验、深蓝杂志、金色指数、高能增长、声波霓虹
- **1020 个版式页面**：从几十种图表、SWOT/波特五力/商业模式画布等分析模型，到架构图、时间线、图文画廊
- **8576 个可调控件**：2372 个滑杆、4276 个开关、1825 个下拉——拖一下滑杆就能增减页面模块

> 我们花了两个多月，和团队里最专业的设计师一起打磨这套 Skill。丰富的视觉效果只是它的表象——真正想解决的问题是：**让生成之后如何编辑这件事，比生成本身更重要。**

🔑 **核心概念解读**

**网页 PPT（HTML Deck）**
- 专业说：基于 HTML/CSS/JavaScript 的交互式演示文稿
- 通俗说：就像把 PPT 做成网页，但能播放、能编辑、能导出

**版式池（Layout Pool）**
- 专业说：按页面角色分类的预设计页面模板库
- 通俗说：就像做菜时的菜谱——告诉我这页要讲什么，自动配好对应的"盘子"

**控制台编辑（Console Editing）**
- 专业说：每页附带的参数化编辑界面
- 通俗说：就像你家电视机的遥控器——换台、调音量、换画面都在遥控器上完成

**可编辑 PPTX 导出**
- 专业说：将 HTML 结构逐节点映射为 PPTX 原生元素
- 通俗说：把网页 PPT"翻译"成真正的 PowerPoint 文件，领导拿到后还能继续改

💡 **切实可落地的例子**

**场景 1：年终总结汇报**
- **痛点**：一年数据一堆，领导要明天看到 PPT，手动排版太累
- **方案**：把年度报告文档丢给 Agent，说"帮我做一份年终总结汇报 PPT，选数据图表风格"
- **具体实现**：
```bash
# 安装 skill
npx skills add https://github.com/chuspeeism/dashiAI-ppt-skill --skill dashiai-ppt

# 在 Claude Code 中
把这份年度报告文档生成一份年终总结 PPT，10 页左右，用数据图表风格。
```
- **效果**：几分钟后拿到完整 PPT，所有数据图表自动排版好，不满意还能拖滑杆调模块数量

---

**场景 2：融资路演材料**
- **痛点**：下周见投资人，需要一套有说服力的路演 PPT
- **方案**：把商业计划书发给 Agent，指定"高能增长风"或"金色指数风"
- **具体实现**：
```bash
根据这份商业计划书生成融资路演 PPT，用金色指数风格，15 页，突出增长数据和市场规模。
```
- **效果**：自动选用资金流、指数、里程碑等适合路演的版式，视觉专业有说服力

---

**场景 3：行业研究报告**
- **痛点**：调研了几十个竞品，要整理成完整的分析报告 PPT
- **方案**：用"色谱图表风"或"冷白调研风"，自动填充 SWOT、波特五力、PEST 等分析模型
- **具体实现**：
```bash
把这些竞品分析资料整理成行业研究报告 PPT，用冷白调研风格，要包含 SWOT 和波特五力分析。
```
- **效果**：20 多种分析模型版式直接用，图表、雷达图、瀑布图自动填充数据

⚠️ **注意事项**

- **环境要求**：需要 Node.js 18+ 和 npm，首次生成会自动安装依赖
- **导出 PPTX/PDF**：需要本机安装 Chrome/Chromium/Edge
- **平台支持**：Claude Code（完美）、Codex（支持）、豆包（刚支持）、普通网页 Chatbot（不推荐）
- **开源协议**：AGPL-3.0（导出引擎 html-deck-to-pptx 独立 MIT 开源）
- **本地运行**：生成、编辑、导出都在本机完成，内容不上传，安全
- **消耗 token**：10 页 PPT 约 20 万 token，一个额度窗口够生成 6-7 套

💡 **为什么是 HTML PPT——但不止是 HTML**

- **更适合 Agent 生成和修改**：HTML/JSON 是文本，Agent 能直接读、改、校验
- **表现力更高**：入场动画、翻页动画、交互控件、明暗模式
- **产物本身就是编辑器**：生成的不是张贴图，而是一个网页版 PPT 编辑器
- **交付更轻**：一键打包成单文件 HTML，离线可开
- **不把你锁死在网页里**：一键导出成真实的 PPTX，文字保持可编辑

🔮 **常见问题**

**真的能导出可编辑的 PPTX 吗？**
能。这是这个 Skill 和"网页伪装的假 PPT"最大的区别。导出引擎逐节点把 HTML 版式还原成 PPTX 原生元素。

**生成一套 PPT 大概消耗多少 token？**
一套 10 页的 PPT 实测约 20 万 token（随文档长度浮动）。按 Claude Code 一个 5 小时额度窗口粗算，大约够生成 6~7 套。

**我在浏览器里改的内容保存在哪里？**
通过本地预览服务（`http://127.0.0.1:<端口>/`）打开时，改动自动写回 `index.html` 本体。

**需要联网吗？我的内容安全吗？**
内容层面零上传：你的文档和 PPT 内容不会发送到任何服务器，生成、编辑、导出都在本机完成。首次生成时 npm 会自动安装依赖，以及任务完成后的静默版本检查。
